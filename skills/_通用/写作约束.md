# 写作约束 (Writing Constraints)

> **所有内容创作类 Skill 必须严格遵守以下约束。**

---

## 1. 🚫 绝对禁止的符号

**以下符号在文中绝对不能出现**（标题和代码块除外）：

| 禁止符号 | 代替方案 |
|---------|---------|
| **破折号** (`——`, `—`, `--`) | 改成逗号，或者拆分成两句 |
| **引号** (`""`, `''`, `「」`, `『』`) | 引用别人说的话用 `xxx说过：`；书名号和强调性引号用 `**加粗**` 替代 |

---

## 2. 🤖 AI 味检测列表 (AI High-Frequency Words)

**检测到以下词汇/句式时，视为"AI味太重"，必须修改：**

### 2.1 高频口头禅
- 好家伙
- 一开始也没当回事儿 / 起初我也不信
- 不吹不黑
- 玄乎 / 唬人
- 值得一提的是 / 不得不说 / 毋庸置疑
- 众所周知
- 事实上

### 2.2 典型的 AI 起手式/转折
- 让我们来看看...
- 在这个信息爆炸的时代...
- 随着科技的发展...
- 首先...其次...最后...
- 不是...而是...（反复使用的机械转折；正文偶尔 1 次口语用法见 3.5）
- 总而言之 / 综上所述

**执行要求**：正文、标题、金句、小标题、承接句里都不要用这类结构。发现一次就直接重写成直说。

### 2.3 代入式权威
- 你以为...其实...
- 很多人觉得...实际上...
- 很多人一听...脑子里浮现的是...
- 能不能...能。而且...
- 你不是一个人 / 不是你的错 / 你大概率会...

**执行要求**：不要替读者预设答案、心理活动和处境，再站高位纠正。只说你看到的判断，让读者自己对照经验。

### 2.4 公式化取材与判断壳

- `今天整理素材的时候，我刷到……`
- `今天整理我的素材时，我看到……`
- `真正让我停下来看的，是……的差别 / 区别`
- `我把这条内容从头到尾翻了一遍，最值得关注的地方是……`（不得作为连续稿件的默认承接壳）

**执行要求**：整理素材、浏览来源和自动任务取材都属于内部过程，不是读者关心的事件。开头直接写内容对象、结果、动作、数字、问题、产品用途或作者判断。涉及比较时直接写比较结果，不先表演“停下来”。

## 3.5 🗑️ 套话替换

| ❌ 不要写 | ✅ 要写成 |
|----------|----------|
| 不是...而是...（同篇第 2 次起，或用在标题、金句、小标题） | 直接说后半句 |
| 与其...不如... | 直接说建议 |
| 一方面...另一方面... | 分两段说 |
| 总而言之 | 直接说结论 |
| 综上所述 | 删掉，直接收尾 |
| 你以为...其实... | 直接说你的判断 |
| 很多人觉得...实际上... | 直接说实际情况 |
| 能不能...能。而且... | 直接给结论 |

补充：
- 口语里的“不是 A，是 B”每篇正文最多 1 次，例如“不是Claude不强，是大家的心态变了”；不得用在标题、开头第一句、小标题、金句和结尾，不得连续或成对排比，更不得当成全文的判断骨架。“看似 A，实则 B”“表面 A，深层 B”“与其 A，不如 B”仍然禁用。
- 不要把“不是...而是...”当标题公式
- 不要把“不是...而是...”当金句
- 不要把“不是...而是...”塞进承接句
- 不要闯进读者脑子里替他想一遍
- 不要用自问自答扮演老师批作业

## 4. ⚠️ 风格红线

1.  **拒绝说教**：不要用“你应该”、“你必须”。用“我建议”、“我的做法是”。
2.  **拒绝伪真实**：不要把自己包装成全知全能的专家，也不要为了显得真实而强塞折腾、失败、自嘲或局限。只有与主题和结论范围直接相关的经历才进入正文。
3.  **拒绝冷漠**：不要像说明书一样冰冷。要有温度，要像朋友聊天。
4.  **拒绝精巧句**：不要把判断压成对仗句、海报式警句或押韵短句。同一个意思用大白话说全，例如“敢不敢交给它，还得看它肯不肯停”改成“能不能放心交给它，那得看他出问题的时候会不会停下来”。结尾一句金句可以有，不要每段都来一句。
5.  **口水词放行**：说实话、尼玛、我去、那这、这个、怎么说、我寻思着、哈哈、。。等本人真实会写的口语不算 AI 味，按语境自然使用，不设数量。清单见 `风格档案/我的风格.md` 〇.5。
6.  **拒绝开头撞型**：每篇准备 3 个不同原型，与最近 5 篇草稿或发布稿对照后选择；跨阶段复用有效记录，开头或对照稿变化时更新，不足 5 篇按实际数量执行。
