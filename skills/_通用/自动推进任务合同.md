# 自动推进任务合同

> 适用于“继续 / 一键推进 / 自动推进”；自主选择、澄清与授权统一遵循项目 `AGENTS.md`。

## 范围与推进

- 未指定对象时，调度器每轮选择最多 3 篇内容，排序与 WIP 按机器配置；明确指定对象或来源的任务按原请求执行。
- 批次限制是选取范围，不是单篇最多三步。完成本轮阶段目标所需的前置、核验与返修连续执行；成品请求持续推进至相应交付物完成。
- 角度、大纲、调研路径和标题在授权目标内由模型决定并记录依据；用户已指定则复用，明确保留人工选择权则等待。既有授权不重复索取。
- `planned` 先核验并补齐证据。取得真实实测结果且通过门禁才进入 `assets_ready`，不能以授权、提示词准备或用户口头确认替代。
- 标题只有候选时保持 `drafted`；用户选定或授权模型终选后保存最终标题、公式和证据映射，再进入 `titled`。
- 单个动作遇到不能自行解决的必要输入或外部阻塞时，保存最近合法状态并继续独立工作。禁止降低验证阈值、伪造事实或跳迁移。

## 记录与汇报

`workflow-dispatch.py` 生成只读 `run_contract`：目的、目标态、失败保持态、范围、验证证据与未知项。`actions` 表示可开始处理，不能证明执行成功；Agent 必须结合会话授权和实际材料执行。

交付前回读文件，核对实际 stage、目录、status 与对应区块，运行结构校验确认没有新增错误。向用户简述已交付结果、实际状态和真实阻塞即可，不逐项朗读合同，不另建形式化运行报告。

外部发布需要对应授权与实际成功记录；`reviewed` 不能仅凭目标平台自动归档。发布脚本只做本地归档。
