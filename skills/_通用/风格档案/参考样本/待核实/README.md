# 待核实语料

> 用于暂存来源不明的语料（❓ 待核实标记）。
>
> 风格学习师 SKILL 的"模式零：语料来源核实"明确规定：
> - 任何不能确认是用户本人原创的语料，**不得直接进入 `我的风格.md`**
> - 在用户能进一步核实之前，先放入本目录，标记 ❓
> - 用户后续核实后，按以下规则分流：
>   - 确认是本人原创 → 移入 `参考样本/` 上级（如果做爆款分析）或直接由风格学习师纳入 `我的风格.md` 并加 📝/🎙️ 标记
>   - 确认是他人作品 → 移入 `参考样本/[作者名].md` 作为对标库内容
>   - 长期无法核实 → 在月度回顾中清理掉

**禁止**：在文件标头明确写"待核实"前，把这里的内容当成本人风格写入档案。
