# HKR 选题质检

> 用途：在 7 维度评估前，先用更轻的方式判断一个选题值不值得继续推进。HKR 只做预筛和补强，不替代 `爆款核心定义.md` 的 7 维度体系。

## 三个问题

| 维度 | 判断问题 | 高分信号 | 低分信号 |
|------|----------|----------|----------|
| H：好奇感 | 读者会不会想点开看下去 | 反常识、现场感、悬念、结果出乎意料 | 主题正确但平淡，像资料整理 |
| K：信息量 | 读者能不能学到新东西 | 有实测、数据、案例、步骤、对比、资料源 | 只有观点，没有证据和新信息 |
| R：共鸣感 | 读者会不会觉得这说到我了 | 说中真实处境、具体烦恼、成本、焦虑、期待 | 只站在作者视角，和读者关系弱 |

## 评分规则

每项 0-10 分。

| 结果 | 判定 | 动作 |
|------|------|------|
| 三项都 >= 8 | S 级候选 | 优先推进，进入 7 维度精评 |
| 两项 >= 8 且另一项 >= 6 | A 级候选 | 可以推进，补弱项 |
| 只有一项 >= 8 | 潜力不足 | 先换角度或补素材 |
| 三项都 < 6 | 暂不推进 | 建议弃用、合并或等待新素材 |

## 输出格式

写入 `## 选题评估` > `### HKR质检`：

```markdown
### HKR质检

| 维度 | 分数 | 判断依据 | 补强动作 |
|------|------|----------|----------|
| H 好奇感 |  |  |  |
| K 信息量 |  |  |  |
| R 共鸣感 |  |  |  |

**结论**：S/A/B/C 级候选
**最需要补强**：好奇感 / 信息量 / 共鸣感
```

## 和现有体系的关系

- H 主要对应：打断力、人性触发
- K 主要对应：认知刷新、作品支撑、可收藏性
- R 主要对应：身份锚定、人性触发

如果 HKR 预筛弱，不要强行用 7 维度把选题评高。先补素材、换角度，或保留为后续裂变。
