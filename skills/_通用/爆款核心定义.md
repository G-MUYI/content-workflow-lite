## 二、爆款标题的定义

### 本质：打断

标题的唯一任务是**打断读者的注意力流动**，让他在3秒内不得不停下来。

### 三要素（三选一即可，三者皆有必停）

| 要素 | 定义 | 例子 |
|------|------|------|
| **意外** | 和读者预期不一样 | "这个工具居然能自动整理文件" |
| **相关** | 和读者有直接关系 | "每天花3小时整理文件的人，这个给你" |
| **紧迫** | 错过会有损失 | "这个免费工具快下架了" |

### 标题不是什么

- ❌ 不是"抓眼球"（抓完就没了）
- ❌ 不是"标题党"（点进去失望）
- ✅ 是"让人不得不停下来，然后不后悔点进来"

## 三、爆款文章的定义

### 本质：交换

读者用时间换你的内容，这是一笔交易。爆款文章 = 交易条件极度诱人。

### 核心公式

```
爆款 = 认知刷新 × 人性触发 × 身份锚定
```

| 要素 | 定义 | 读者内心OS |
|------|------|-----------|
| **认知刷新** | 让人发现新的可能性 | "原来可以这样做" |
| **人性触发** | 直击底层人性 | "我也想要/我也怕/我也好奇" |
| **身份锚定** | 让他觉得这说的就是他 | "这个需求我也有" |

**三者缺一，效果减半。**

### 什么让文章值得交换

- 要么你给的东西**太稀缺**（别人没有的作品/视角）
- 要么你给的成本**太低**（3分钟就能学会/马上能用）
- 要么你给的情绪**太爽**（"我也想要这个"）

## 四、7维度评估体系

> **2026-03-10 更新**：基于 Seedance 爆款文章（3.1W+ 阅读，收藏率 22.7%）的数据复盘，新增"可收藏性"维度。

| 维度 | 权重 | 满分条件 |
|------|-----|---------|
| **打断力** | ⭐⭐⭐ | 意外+相关+紧迫，至少占2个 + 需求验证（有搜索量/讨论量） |
| **认知刷新** | ⭐⭐⭐ | 让人发现"原来可以这样" |
| **人性触发** | ⭐⭐ | 直击底层人性：懒/贪/怕/好奇/虚荣/掌控 |
| **身份锚定** | ⭐⭐ | 精准定位（从"内容创作者"细化到"想用AI做视频但不会写提示词的人"） |
| **作品支撑** | ⭐⭐⭐ | 有真实作品/案例支撑 |
| **可收藏性** | ⭐⭐⭐ | 内容值得读者保存反复查看（有可直接复制的模板/清单/提示词） |
| **工作量** | ⭐ | 30分钟内能写完（权重降低，与数据表现无明显相关性） |

### 打断力升级说明

**新增子项：需求验证**
- 这个话题有多少人在搜索/讨论？
- 区分"热点窗口期"（新工具发布 ≤7天）vs"常青内容"
- 热点窗口期的选题优先级更高

### 身份锚定升级说明

**要求更精准**：
- ❌ 不够精准："内容创作者"、"自媒体人"
- ✅ 精准定位："想用AI做视频但不会写提示词的人"、"被新概念搞焦虑的人"

### 可收藏性详解

| 可收藏内容类型 | 示例 | 收藏率预期 |
|--------------|------|-----------|
| 可直接复制的提示词 | Seedance 4大提示词技巧 | 20%+ |
| 操作清单/步骤 | 6张截图清单 + 实操步骤 | 15%+ |
| 对比表格 | Skills vs 传统提示词对比 | 10%+ |
| 公式/模板 | 标题公式、大纲模板 | 10%+ |

**判断标准**：读者会不会想"保存下来以后用"？

### 人性触发详解

| 底层人性 | 触发点 | 读者内心OS |
|---------|-------|-----------|
| **懒/省力** | 这个工具能帮我省事 | "我也不想费劲做这个" |
| **贪/想要更多** | 能省时间/省钱/效果更好 | "我也想要这个好处" |
| **恐惧/怕落后** | 别人已经在用了 | "别人都有了，我还没有" |
| **好奇** | 这是怎么做到的？ | "想知道背后的原理" |
| **虚荣/想被认可** | 用这个显得我很厉害 | "如果我也有，别人会觉得我牛" |
| **掌控感** | 我能控制这件事了 | "终于能搞定这个烦人的事了" |

### 爆款潜力等级

> **2026-03-10 更新**：双轨制评级 — 区分"流量型"和"IP型"，平衡涨粉与建立个人品牌

#### 轨道1：流量型S级（涨粉）

| 等级 | 条件 | 预期 | 频率 |
|------|------|------|------|
| 🔥🔥🔥 流量型S级 | **必须同时满足**：<br>1. 新工具/新功能发布 ≤ 7天（热点窗口期）<br>2. 有明确实操价值（读完能上手）<br>3. 市场需求验证（搜索量/讨论量高）<br>4. 7维度中至少6个满分 | 10K+ 阅读<br>快速涨粉 | 机会主义<br>有热点就抓 |

**目标**：抓住热点窗口期，快速扩大影响力

**典型案例**：Seedance 2.0 教程（31K阅读）

#### 轨道2：IP型S级（建品牌）

| 等级 | 条件 | 预期 | 频率 |
|------|------|------|------|
| 🔥🔥🔥 IP型S级 | **必须同时满足**：<br>1. 有独特的方法论/系统（别人没有的）<br>2. 有真实作品验证（不是纸上谈兵）<br>3. 可收藏性强（⭐⭐⭐满分）<br>4. 7维度中至少5个满分 | 1K-5K 阅读<br>高质量粉丝 | 稳定输出<br>每月1-2篇 |

**目标**：沉淀方法论，建立个人品牌，提升粉丝粘性

**典型案例**：写作工作流系统、6个Skills串联流程

**IP型与流量型的区别**：

| 维度 | 流量型S级 | IP型S级 |
|------|----------|---------|
| 核心价值 | 抓住热点，解决当下问题 | 沉淀系统，解决长期问题 |
| 时效性 | 强（窗口期≤7天） | 弱（常青内容） |
| 可复制性 | 工具教程（可直接抄） | 方法论（需要理解） |
| 粉丝质量 | 追工具的人（粘性低） | 认同系统的人（粘性高） |
| 阅读量 | 10K+（爆发式） | 1K-5K（稳定） |
| 品牌价值 | 低（工具过时就失效） | 高（系统不会过时） |

#### 其他等级

| 等级 | 条件 | 建议 |
|------|------|------|
| 🔥🔥 A级 | 常青内容 + 观点文 + 技术解读<br>5-6维度满分 | 优先写 |
| 🔥 B级 | 4维度满 | 可以写 |
| ⚪ C级 | 3个及以下 | 暂缓 |

#### 特殊内容类型：工具使用技巧

**判定规则**：根据工具发布时间和内容深度，分为3种类型

| 类型 | 定义 | 评级 | 预期阅读 | 7维度特征 |
|------|------|------|---------|----------|
| **新工具教程** | 工具发布 ≤7天<br>从0到1的完整教程 | 流量型S级 | 10K+ | 打断力⭐⭐⭐（窗口期+需求验证）<br>认知刷新⭐⭐⭐<br>可收藏性⭐⭐⭐（可直接抄的步骤） |
| **成熟工具进阶技巧** | 工具发布 >30天<br>独特的使用方法/组合技巧 | IP型S级 | 1K-5K | 认知刷新⭐⭐⭐（"原来还能这样用"）<br>作品支撑⭐⭐⭐（真实案例）<br>可收藏性⭐⭐⭐（可复制的技巧） |
| **工具对比/评测** | 横向对比多个工具<br>帮助选择 | A级 | 500-1K | 认知刷新⭐⭐（信息整合）<br>身份锚定⭐⭐（解决选择困难） |

**示例**：

- **新工具教程**：《Claude Code 从入门到精通，我花一天替你跑通了。直接抄。》（发布后3天内）
  - 评级：流量型S级
  - 理由：窗口期内 + 完整教程 + 可直接复制的步骤

- **成熟工具进阶技巧**：《Claude Code 的6个隐藏技巧，让我的开发效率翻倍》（发布后3个月）
  - 评级：IP型S级
  - 理由：独特方法论 + 真实使用案例 + 可复制的技巧组合

- **工具对比**：《Claude Code vs Cursor vs GitHub Copilot，我用了3个月的真实对比》
  - 评级：A级
  - 理由：信息整合价值 + 帮助决策，但缺乏独特方法论

**内容策略建议**：
- **短期（涨粉）**：抓流量型S级，有热点就抓，不强求
- **长期（建IP）**：稳定输出IP型S级，每月1-2篇
- **组合拳**：用流量型涨粉 → 用IP型留人 → 形成品牌认知

### 工作量评估标准

| 星级 | 预估时间 | 适用场景 |
|------|---------|---------|
| ⭐ | 20-30分钟 | 已有作品、简单展示 |
| ⭐⭐ | 30-45分钟 | 需要整理素材、补充背景 |
| ⭐⭐⭐ | 45-60分钟 | 需要对比分析、多角度论证 |
| ⭐⭐⭐⭐ | 60-90分钟 | 需要调研、实测、深度分析 |

## 五、"爆"和"好"的区别

| 类型 | 特点 | 结果 |
|------|------|------|
| **只爆不好** | 情绪煽动、蹭热点、标题党 | 爆完就完，下一篇还得重新赌 |
| **只好不爆** | 深度、专业、有料 | 叫好不叫座，传播不开 |
| **又爆又好** | 真实作品 + 有用 + 共鸣表达 | 爆完有人问"这个能帮我做吗" |

**目标是第三种。**

## 六、素材来源原则

最好的素材，往往不是学来的。更常见的来源是：

1. **你造的东西**（真实的作品、工具、解决方案）
2. **你造东西的过程**（踩的坑、学到的东西、有趣的发现）
3. **你发现的需求**（看到的痛点、遇到的问题、普遍的困扰）
4. **你对热点的视角**（结合你的Maker身份解读热点）

越具体越好，越真实越好。作品和过程就是最大的差异化。

## 七、检验标准（写完后问自己）

1. 标题能不能让人停下来？（意外/相关/紧迫，至少占一个）
2. 文章有没有让人发现新可能？（读完觉得"原来可以这样"）
3. 读者能不能对号入座？（"这个需求我也有"）
4. 有没有你自己的真实作品/案例？（不是抄来的道理）
5. 触发了什么底层人性？（懒/贪/怕/好奇/虚荣/掌控）
6. 看完后读者会不会想找你？（能不能带来信任/转化）
