# 热点来源适配

> 用途：为 AI 内容发现热点和判断时间窗口。它只负责发现线索，不替代原始来源核实。

## Provider

| provider | 适用情况 | 限制 |
|---|---|---|
| `web` | 默认联网搜索，覆盖面广 | 需要自行去重和判断时间 |
| `aihot` | AI 热点、精选和滚动时间窗 | 第三方策展服务，不能作为唯一事实源 |
| `manual` | 用户提供链接、截图或素材 | 覆盖面取决于用户输入 |

## 路由

1. 用户给了原始素材，先用 `manual`。
2. 用户问 AI 圈最近热点，可用 `aihot` 发现候选。
3. 需要跨领域、官方事实或 AI HOT 不可用时，用 `web`。
4. 同一次调研可组合 provider，但每条线索要记录来自哪里。

## AI HOT 使用边界

- 只访问公开、匿名、只读端点。
- “过去 24 小时”与“最近 7 天”按服务端时间口径查询。
- 同时保存 `published_at`、`discovered_at` 和采用的时间轴口径。
- 标题和摘要只用于筛选线索；关键事实回 `links.original` 或官方来源复核。
- API 失败时标记 provider 不可用并降级到 web，不用训练记忆冒充实时结果。
- 同一 URL 可保存 ETag，重复查询时使用条件请求。

## 写入格式

写入 `## 市场调研 > ### 深度调研 > #### 热点来源记录`：

```markdown
#### 热点来源记录

| 线索 | provider | published_at | discovered_at | 时间口径 | 原始来源已核实 |
|------|----------|--------------|---------------|----------|----------------|
| | web / aihot / manual | | | timeline / published / user-provided | 是 / 否 |
```

`原始来源已核实：否` 的线索只能用于继续搜索，不得直接写成正文事实。
