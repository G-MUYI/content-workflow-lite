# 通用示例（非本人语料）

> 本文件存放与任何个人无关的通用写作示例，供各 Skill 的表格和方法说明引用。
> 风格学习师学习语料时，**不得**把本文件当作任何人本人的风格基线。

## 开头类型示例

| 类型 | 示例 |
|------|------|
| 故事型 | "前两天，有个读者在后台问我……" |
| 场景型 | "昨天晚上，这个工具悄悄上了一个新功能" |
| 悬念型 | "本来数据一直不好，转折点出现在我开始做另一件事之后" |
| 反常识型 | "现在回头看，我成长最快的几个阶段，几乎都是从换方向开始的" |
| 直给型 | "这事儿能难住我吗？" |

## 结尾类型示例

| 类型 | 示例 |
|------|------|
| 标准收尾 | "好了，今天的分享就到这儿啦~" |
| 资源引导 | "地址在这里：https://example.com" |
| 互动引导 | "有知道的朋友可以评论区留言" |
| 金句升华 | "该换就换，不要折磨自己" |

## 引文来源标记示例（写入 `我的风格.md` 时必须遵守）

```markdown
| 词汇 | 用途 | 真实例 |
|------|------|--------|
| （你的口癖） | 表达思考 | "（你的原话）" 📝 (来源篇目) |

```
