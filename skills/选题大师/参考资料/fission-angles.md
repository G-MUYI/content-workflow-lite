# 裂变角度参考

## 五大裂变角度

### 1. 新手版（最小步骤）
- **核心思路**：把复杂流程简化到3步以内
- **目标用户**：完全零基础的小白
- **标题特征**：小白、入门、最简单、0基础
- **转化示例**：
  - 原选题：用Cursor写自动化脚本
  - 新手版：**0代码基础，用Cursor写第一个脚本只要3步**

### 2. 进阶版（更稳定/更可控）
- **核心思路**：在基础方法上增加参数控制、异常处理
- **目标用户**：已入门但想要更好效果的用户
- **标题特征**：进阶、高级、稳定、可控、自定义
- **转化示例**：
  - 原选题：AI生成设计稿
  - 进阶版：**AI出图不稳定？加这3个参数立刻可控**

### 3. 避坑版（最常见3个错误）
- **核心思路**：总结用户最容易犯的错误
- **目标用户**：已经在用但效果不好的用户
- **标题特征**：别踩坑、常见错误、90%的人都错了
- **转化示例**：
  - 原选题：用AI写方案
  - 避坑版：**用AI写方案，这3个错误让你白忙一天**

### 4. 对比版（A vs B 何时选）
- **核心思路**：横向对比两个工具/方法的适用场景
- **目标用户**：有选择困难的用户
- **标题特征**：vs、对比、哪个好、怎么选
- **转化示例**：
  - 原选题：AI抠图工具
  - 对比版：**PS AI vs 在线抠图：设计师什么情况用哪个**

### 5. 模板赠送版（可直接复制使用）
- **核心思路**：提供可复制的提示词/表格/清单
- **目标用户**：不想重复造轮子的用户
- **标题特征**：模板、提示词、直接复制、一键用
- **转化示例**：
  - 原选题：AI整理会议纪要
  - 模板版：**直接复制：让AI整理会议纪要的万能提示词**

---

## 裂变转化公式

```
原选题 + 裂变角度 = 新选题

【原选题】用AI做海报
├── 新手版：不会设计也能做，AI海报3步出图
├── 进阶版：AI海报总是差点意思？调这3个参数
├── 避坑版：AI做海报的3个坑，第一个我踩了一周
├── 对比版：Midjourney vs Canva AI，做海报选哪个
└── 模板版：送你5条海报提示词模板，直接复制
```

---

## 裂变角度选择建议

| 原选题特点 | 推荐裂变角度 |
|-----------|-------------|
| 步骤较多、有门槛 | 新手版 |
| 效果不稳定 | 进阶版 |
| 用户反馈问题多 | 避坑版 |
| 有多个可选方案 | 对比版 |
| 涉及提示词/流程 | 模板赠送版 |

| 裂变角度 | 价值点 | 触发动作 |
|---------|--------|---------|
| 新手版 | 降低门槛 | 收藏备用 |
| 进阶版 | 提升效果 | 立即尝试 |
| 避坑版 | 节省时间 | 转发提醒 |
| 对比版 | 帮助决策 | 收藏参考 |
| 模板版 | 直接可用 | 收藏+转发 |
