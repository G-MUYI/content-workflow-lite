## 1. 选题生成模板 (模式一)

```
✅ 爆款选题分析完成

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1️⃣ [选题标题]（角度：[作品型/幕后型/热点型]）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【核心概念】
[一句话说清楚核心卖点]

【爆款三角验证】
- 意外：[哪里反直觉？]
- 相关：[跟谁有关？]
- 紧迫：[为什么要现在看？]

【6维度评估】
┌─────────┬────────┬──────────────────────────┐
│ 维度     │ 评分   │ 理由                      │
├─────────┼────────┼──────────────────────────┤
│ 打断力   │ ⭐⭐⭐ │ [意外/相关/紧迫占几项]    │
│ 认知刷新 │ ⭐⭐⭐ │ [刷新了什么旧认知]        │
│ 人性触发 │ ⭐⭐   │ [击中了什么人性弱点]      │
│ 身份锚定 │ ⭐⭐   │ [谁会觉得自己被cue到了]   │
│ 作品支撑 │ ⭐⭐⭐ │ [核心证据是什么]          │
│ 工作量   │ ⭐     │ [预估耗时]               │
└─────────┴────────┴──────────────────────────┘

综合潜力：🔥🔥🔥 [S/A/B/C] 级

【劣势/风险】
• [可能遇到的挑战]
```

```

...

```

```
1. [最突出的优势]
2. [为什么今天适合写]
3. 预估 X 分钟能写完

写作建议：
- 开头：[怎么抓住人]
- 核心：[交付什么]
- 结尾：[引导什么行动]
```
