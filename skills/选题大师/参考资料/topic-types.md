# 选题类型参考

## 五大选题类型

### 1. 痛点解决型
- **特点**：直击用户痛点，提供明确解法
- **适合场景**：用户有明确问题需要解决
- **标题风格**：XXX怎么办？这样做就行
- **示例**：
  - 设计稿改100遍？用这个AI工具一次定稿
  - AI生成的图总是糊？3个设置改完立刻清晰

### 2. 工具清单型
- **特点**：横向对比多个工具/方法
- **适合场景**：用户有选择困难，需要推荐
- **标题风格**：X个XXX工具推荐/对比
- **示例**：
  - 设计师必备的5个AI抠图工具
  - 做PPT用哪个AI？测了10个只推荐这3个

### 3. 学习复现型
- **特点**：手把手教学，可跟着做
- **适合场景**：新技术/新工具的入门教程
- **标题风格**：从0到1、手把手、跟我学
- **示例**：
  - 从0学会用Cursor写自动化脚本（小白版）
  - 跟着做：用AI一键生成小红书封面

### 4. 避坑吐槽型
- **特点**：总结常见错误和踩坑经验
- **适合场景**：用户已开始尝试但遇到问题
- **标题风格**：别踩坑、我踩过的坑、常见错误
- **示例**：
  - 用Midjourney出图，90%的人第一步就错了
  - AI写文案的3个大坑，第2个我踩了一周

### 5. 工作流模板型
- **特点**：提供可复用的流程/模板/提示词
- **适合场景**：用户需要标准化、可复用的东西
- **标题风格**：模板、提示词、工作流、一键复制
- **示例**：
  - 设计师AI工作流模板：从需求到交付只要3步
  - 直接复制：我日常用的10条AI提示词

---

## 选题类型选择建议

| 用户状态 | 推荐选题类型 |
|---------|-------------|
| 有明确痛点但不知道怎么解决 | 痛点解决型 |
| 知道要用AI但不知道用哪个 | 工具清单型 |
| 刚入门想学但不知道从哪开始 | 学习复现型 |
| 已经在用但效果不好 | 避坑吐槽型 |
| 想要提效但不想重复造轮子 | 工作流模板型 |

## 同素材多角度映射（新增）

> 同一份素材，可以同时映射到多个类型；不要默认只能选一个。

以同一个工具素材为例，常见会裂变出 4 种文章：

| 用户真实需求 | 推荐类型 | 典型标题承诺 |
|-------------|---------|-------------|
| 想赶紧上手 | 学习复现型 | "从0到1跑通" |
| 想先收藏备用 | 工作流模板型 | "提示词清单 / 模板直接复制" |
| 想知道选哪个 | 工具清单型 | "测了X个，只推荐这3个" |
| 想理解底层逻辑 | 痛点解决型 / 方法论向 | "为什么这样做更稳" |

### 判断优先级

1. **窗口期强** → 先做学习复现型
2. **模板价值强** → 先做工作流模板型
3. **选择困难强** → 先做工具清单型
4. **你有独特系统** → 先做方法论向

## 30分钟写完的技巧

### 最小交付形态（L1）

| 选题类型 | L1内容形态 | 字数 |
|---------|-----------|------|
| 痛点解决 | 3步解决法 | 300-500字 |
| 工具清单 | 对比表格 + 推荐理由 | 300-500字 |
| 学习复现 | 截图 + 步骤说明 | 400-600字 |
| 避坑吐槽 | 错误清单 + 正确做法 | 300-500字 |
| 工作流模板 | 流程图 + 提示词 | 300-500字 |

### 快速写作公式

```
1. 开头（50字）：一句话说清痛点
2. 主体（300字）：3-5个要点/步骤
3. 结尾（50字）：总结 + 引导收藏
```
