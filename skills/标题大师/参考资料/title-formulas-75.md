# 小红书标题公式库（原创 75 式）

> 用途：给标题大师做变体扩充和发布后复盘。公式只负责组织表达，不负责制造承诺。

## 使用边界

1. 先从正文提取可兑现的核心结论，再选公式；禁止先套公式再倒逼正文。
2. 标题中的数字、时间、结果、案例、身份与权威必须能映射到原始素材、已验证证据或可公开核验的来源。
3. `candidate / missing` 状态的 Hook 素材不得进入标题；只有 `verified` 才能作为事实使用。
4. 标准与速发通常生成 3–5 条差异明显的候选，flagship 8–12 条并跨至少 4 类；用户指定数量优先，不遍历全部 75 条或为凑数扩写。
5. 终选时记录公式 ID。复盘时比较“公式分类 × 平台 × 内容目标”，不要只比较单篇阅读量。

## 推荐取样矩阵

| 内容目标 | 优先分类 | 次选分类 |
|---|---|---|
| 拉新 / 停留 | C 反差、D 问题、J 热点 | A 结果、E 身份 |
| 收藏 | F 教程、G 清单 | B 效率、H 选择 |
| 决策 | H 比较、A 成本 | I 案例、K 方法 |
| 信任 / IP | I 复盘、K 方法 | C 反差、L 讨论 |
