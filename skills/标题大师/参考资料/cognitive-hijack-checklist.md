# 标题点击理由与兑现检验

> 这是标题 Skill 的方法参考，不另设审批或无限打磨流程。标题应让目标读者看懂价值，并兑现正文承诺；强情绪按目标使用。

## 一、可用机制

| 机制 | 用途 | 使用边界 |
|---|---|---|
| 预期违背 | 突出真实反差 | 对比双方必须有依据 |
| 信息缺口 | 激发对方法或结果的好奇 | 不隐藏会改变承诺的关键条件 |
| 身份相关 | 让目标读者识别与自己的关系 | 不编造群体焦虑或替读者预设心理 |
| 结果吸引 | 呈现值得点击的交付 | 不把预期效果写成已实现收益 |

这些是表达工具，不要求每条标题标满所有机制。清楚的使用场景、可复制模板或选择标准也可构成点击理由。

## 二、马斯洛元素按需使用

成本、视觉、猎奇、人群、场景、数据、对比等元素，按正文事实与传播目标选取，不设至少三个或必含视觉、成本的配额。完整方法按需读取 `../../爆款内容策划师/参考资料/maslow-13-elements.md`。

## 三、统一验收

每条候选核验一次：

1. 对目标读者的价值是否清楚，是否与 `content_goal` 相符。
2. 数字、时间、效果、身份、案例和权威是否有真实来源与适用边界。
3. 正文、封面和发布包是否兑现同一个承诺。
4. 是否自然、具体，避开通用写作约束中的禁用句式。

虚假承诺、失实事实和关键边界缺失必须修复。仅因没有震惊感、没有极端落差或使用了描述性表达，不淘汰本来准确有用的标题。

## 四、按内容目标调整

- `growth`：在真实承诺范围内强化反差、好奇与传播动机；强刺激是可用选项，不是假情绪配额。
- `collect`：让读者知道可保存、复制或反复使用什么。
- `decide`：明确比较对象、判断标准与适用场景。
- `trust`：突出有依据的判断、解释力和作者的选择。

## 五、可选增强

候选没有清楚的点击理由时，再尝试更具体的动词、场景、结果、真实反差或更短表达。不得从例子里借用未经核实的金额、耗时或经历。

候选已有足够差异、符合目标并通过兑现检查即可终选或交付。不因“还能更狠”持续补写；候选数量与人工终选边界以标题 Skill 和项目 AGENTS.md 为准。
