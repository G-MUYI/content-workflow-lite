# 标题公式详解

## 公式速查表

| 类型 | 打断要素 | 公式模板 |
|------|---------|---------|
| 时间反差 | 意外 | 如何用{短时间}，{巨大成果} |
| 身份锁定 | 相关 | 如果你{困境}，接下来{时间}别再{行动} |
| 反常识 | 意外 | {常见概念}是个{否定词}（真正厉害的人{反常识观点}） |
| 技能价值 | 相关+紧迫 | 未来{时间}更{形容词}的能力：{能力} |
| 问题揭露 | 意外+相关 | 为什么{现象}反复出现 |
| 直击痛点 | 意外+相关 | 如果你{现象}，这篇文章是写给你的 |
| 反向认同 | 相关 | 大多数人都会{消极结果} |
| 强刺激流量 | 意外+紧迫 | {强情绪判断}+{具体结果/冲突/数字} |

## 可选起点：从真实反应出发

> 反应与公式都是生成方法，可按目标择用，不要求固定顺序或强情绪。本文的数量、强度与示例是方法建议；验收统一读取标题 Skill 与 `cognitive-hijack-checklist.md`。示例中的价格、时间、结果和经历不是可直接使用的事实。

### 核心问题：看完这篇，身体反应是什么？

不要想"这篇讲了什么"，要想"如果我刷到这件事，第一句话会说什么"。

### 4 类反应起点

**① 震惊反应**（预期违背）

问：看完最想说的那句话是什么？

| 文章里的事实 | 反应句示例 |
|------------|---------|
| 打一个字就能出展览级海报 | "我以为是花钱做的" |
| GPT 自己补了广告语 | "这合理吗" / "这怎么可能" |
| 一句话提示词出了电影感图 | "离谱到这个程度了" |

**② 省力反应**（成本极端落差）

问：最轻的动作是什么？最重的结果是什么？直接对撞，中间不解释。

| 最轻的动作 | 最重的结果 | 对撞句 |
|-----------|----------|--------|
| 打个字 | 展览级海报 | "打个字给 GPT，出来的图我以为花钱做的" |
| 随手丢一个词 | 品牌官方海报感 | "随手丢个'麦当劳'，出来的图像官方宣传片" |

**③ FOMO 反应**（身份威胁）

问：别人已经在用了，我还不知道，这句话怎么说？

- "别人还在学 PS，我已经打字出海报了"
- "都 2025 年了，还有人不知道 GPT 能这样用"

**④ 不信反应**（信息缺口）

问：听起来不可能，但是真的，怎么吊住对方的好奇心？

- 只说一半，剩下的让读者自己点进来找
- "打了'孤独'两个字，出来的图挂美术馆都合适，他到底怎么做到的"

---

### 具体词 vs 抽象词（必须做的替换）

标题犀利与否，关键不在于技巧，在于用词。具体词自带画面，抽象词只是标签。

| ❌ 抽象词（删掉） | ✅ 具体词（换成这个） |
|-----------------|-------------------|
| 展览级海报 | 我以为是花钱做的 / 挂美术馆也合适 |
| 高级概念海报 | 字变成画面骨架，图围着字长出来 |
| 图像能力很强 | 打一个字，它自己补画面补氛围 |
| 操作简单 | 打个字就行 / 随手丢一个词 |
| 效果很好 | 我以为是设计师做的 |
| 高效 | 30秒 / 一句话 / 打个字 |

**留白比描述更有力**（2026-05-08 补充）

"这种图"比"展览级海报"更强——模糊指代让读者好奇是什么图，描述词直接给了答案反而消解悬念。配合具体成本数字，留白 + 金额是高点击率的组合：

- ❌ `这种展览级海报，以前得花几百找设计师`（描述词把悬念说死了）
- ✅ `这种图，我以前得要花几百找设计师`（"这种图"留白，读者想看是什么图）

规律：**视觉结果可以留白，成本数字要写具体。**

## 1. 时间反差型

### 核心逻辑

用"短时间"和"大成果"的对比制造冲击感

### 公式变体

```
如何用{短时间}，{巨大成果}
花{短时间}做完这件事，顶别人努力{长时间}
一个{时间单位}，彻底改变你和{领域}的关系
{短时间}内，我{成果}
```

### 示例库

- 如何用1天时间，重新设计你的整个人生
- 花3小时做完这件事，顶别人努力3年
- 一个周末，彻底改变你和金钱的关系
- 30天内，我从零开始学会了AI编程

### 适用场景

- 效率提升类内容
- 方法论分享
- 学习经验分享

---

## 2. 身份锁定型

### 核心逻辑

精准描述目标读者的状态，让他们觉得"这说的就是我"

### 公式变体

```
如果你{困境}，接下来{时间}别再{行动}
写给{某类人}
给那些"{某种状态}"的人
如果你也{现象}，这是写给你的
```

### 示例库

- 如果你有很多兴趣却不知道该选哪个，接下来3年别再浪费了
- 给那些"想得太多，做得太少"的人
- 写给每一个觉得自己不够自律的人
- 如果你也有过这种感觉：明明知道该做什么，就是做不到

### 适用场景

- 痛点非常明确的内容
- 针对特定人群的内容
- 需要引发共鸣的内容

---

## 3. 反常识型

### 核心逻辑

挑战大众的常见认知，引发好奇

### 公式变体

```
{常见概念}是个{否定词}（真正厉害的人{反常识观点}）
为什么{常见建议}是最{贬义词}的
别再{常见行动}了，{行动}本身就是问题
别再{常见认知}了，真正有效的是{反常识观点}
```

### 示例库

- 自律是个谎言（真正厉害的人根本不需要它）
- 为什么"找到热爱"是最坑人的建议
- 别再"坚持"了，坚持本身就是问题
- 别再盲目堆任务了，高效的人会主动做减法

### 适用场景

- 有独特观点的内容
- 想要制造话题的内容
- 颠覆认知类的内容

---

## 4. 技能价值型

### 核心逻辑

强调某种能力的价值，激发学习欲望

### 公式变体

```
未来{时间}更{形容词}的能力：{能力}
学会{一件事}，你的{能力}超过{百分比}的人
{人群}最容易忽略的{底层}能力
这个能力，决定了你{领域}的上限
```

### 示例库

- 未来10年更值钱的能力：把想法变成稳定结果
- 学会这一件事，你的表达能力超过90%的人
- 普通人最容易忽略的底层能力
- 这个能力，决定了你赚钱的上限

### 适用场景

- 学习类内容
- 技能分享类内容
- 职业发展类内容

---

## 5. 问题揭露型

### 核心逻辑

揭示问题的本质原因，引发读者的好奇和反思

### 公式变体

```
为什么{现象}反复出现
那些{成功者}，到底做对了什么？
为什么你{行动}了那么多，生活却没有任何改变
{现象}背后的关键问题：{原因}
```

### 示例库

- 为什么半途而废总在重复出现
- 那些年入百万的人，到底做对了什么？
- 为什么你学了那么多，生活却没有任何改变
- 拖延背后的关键问题：节奏一直没稳住

### 适用场景

- 分析类内容
- 洞察类内容
- 深度思考类内容

---

## 6. 直击痛点型

### 核心逻辑

直接描述读者的痛苦状态，引发强烈共鸣

### 公式变体

```
如果你{现象}，这篇文章是写给你的
{数字}个你可能{否定词}知道的{主题}真相
{现象}的人，往往卡在这一步
明明{状态A}，却{状态B}
```

### 示例库

- 如果你也有过这种感觉：明明知道该做什么，就是做不到
- 3个你可能不敢知道的拖延症真相
- 总是焦虑的人，往往卡在这一步
- 明明很努力，却越来越穷

### 适用场景

- 解决方案类内容
- 共情类内容
- 痛点明确的内容

---

## 7. 反向认同型

### 核心逻辑

先承认消极现实，再给出转机，建立信任感

### 公式变体

```
大多数人都会{消极结果}
没关系，{安慰+转折}
{负面现象}背后，常常是{原因}
想走出{消极结果}，先换{条件}
```

### 示例库

- 大多数人都会放弃新年目标
- 拖延背后，常常是方法卡住了
- 没关系，大多数人都会失败
- 想学会编程，先换个思路

### 适用场景

- 安慰类内容
- 共情类内容
- 需要先破后立的内容

## 组合技巧

### 双公式组合

```
反常识 + 问题揭露
= 为什么越努力越累，问题还是反复出现

身份锁定 + 时间反差
= 写给想早起的人：如何用1周彻底改变你的作息

直击痛点 + 反向认同
= 焦虑反复出现的人，先把节奏稳住
```

### 选择建议

| 内容特点 | 首选公式 | 次选公式 |
|---------|---------|---------|
| 有独特观点 | 反常识型 | 问题揭露型 |
| 解决具体问题 | 时间反差型 | 直击痛点型 |
| 针对特定人群 | 身份锁定型 | 直击痛点型 |
| 分析现象本质 | 问题揭露型 | 反常识型 |
| 安慰共情 | 反向认同型 | 身份锁定型 |

## 常规版 vs 狠版

每种公式都有常规版和狠版。选择依据：

| 情况 | 建议 |
|------|------|
| 内容确实硬核，能撑得起 | 用狠版 |
| 内容一般，狠版会让人失望 | 用常规版 |
| 想建立长期信任 | 常规版为主，偶尔狠版 |
| 想快速起量 | 狠版为主 |
| 说的是真话 | 随便选 |
| 说的是包装出来的 | 用常规版，狠版会翻车 |

**核心原则**：狠版必须有真东西撑着，不然就是标题党。

**狠版示例**：
- 时间反差：3天，3000块。然后我把方法删了。
- 身份锁定：说的就是你：学了一年，还在"准备中"。
- 反常识：自律？穷人才需要自律。
- 问题揭露：他们在用AI赚钱，你在用AI写作业。

## 强刺激流量标题吸收版

> 来源：爆款标题大师班两节课的可迁移方法。用户明确允许吸收偏流量、强刺激的内容，但必须做兑现检查。

### 核心判断

强刺激不等于虚假标题。允许把情绪、冲突、数字、对比、悬念拉满，但标题里的结果、场景和承诺必须能被正文交付。

| 可以大胆用 | 不能用 |
|-----------|--------|
| 更强的情绪词 | 正文没有支撑的恐吓 |
| 更明显的冲突 | 夸大收益或保证结果 |
| 更锋利的否定 | 诱导误解的标题党 |
| 更具体的数字 | 编造数据或伪权威 |
| 更短的命令感 | 贩卖焦虑但不给解法 |

### 信息密度 8 种手法

| 手法 | 用法 | 适合内容 |
|------|------|---------|
| 差异对比 | 把两个反差对象放在一起 | 工具前后对比、普通人 vs 高手 |
| 情境错位 | 把常见场景写出不常见结果 | AI 工具、职场、创作实验 |
| 数字 | 用时间、成本、数量、结果制造具体感 | 教程、清单、复盘 |
| 悬念 | 只露出最反常的一半 | 观点文、案例文 |
| 热度 | 借最新工具、热点人物、平台变化 | 强时效内容 |
| 对话场景 | 标题像一句对话或现场反应 | 小红书、朋友圈、短篇 |
| 视角代入 | 让目标读者一眼知道和自己有关 | 新手、内容创作者、运营 |
| 关键词公式 | 标题埋入平台检索词 | 小红书、工具教程 |

### 信息密度补充：制造场景 & 贴标签

> 来源：公众号爆款标题方法论归纳（2026-05-08）。作为"对话场景"和"视角代入"的延伸说明。

#### 制造场景（对"对话场景"的延伸）

**核心差异**：
- 对话场景：标题像真人说出的一句话 → 侧重**口语感**
- 制造场景：标题里有一个视觉化细节，读者脑子里会闪出画面 → 侧重**画面感**

**制造场景的原理**：描述一个具体动作或细节，让读者脑补出完整情节，从而产生"这什么情况，我要看"的冲动。不解释原因，只呈现画面。

**典型例子**：
- 被害女子每天磕头500个，遭多人凌辱（动作+数字，一眼有画面）
- 36个男朋友（数字本身就是画面，脑子里会闪出人群）

**制造场景适合的内容**：
- 有具体细节的故事、案例、事件
- 数字 + 动作组合（"每天XX次"、"花XX天"）
- 能让读者产生"这个细节太具体了，我要看背后原因"的场景

**执行提示**：找文章里最具体的一个动作或数字，直接放进标题，不加解释，靠画面自己说话。

---

#### 贴标签（对"视角代入"的延伸）

**核心差异**：
- 视角代入：提示读者"这篇和你有关" → 功能是**圈定人群**
- 贴标签：直接给一类人命名一个他们认同的标签 → 功能是**触发身份认同**，让被贴中的人主动说"这说的就是我"

**贴标签更强的原因**：
1. 被贴中的人会主动转发（身份认同驱动）
2. 没被贴中的人会好奇这类人是什么样（好奇驱动）
3. 标签带情绪色彩时会制造悬念（"匪气"是好是坏？）

**常用标签类型**：

| 类型 | 示例 |
|------|------|
| 年龄 + 状态 | "中年以后"、"35岁以后"、"毕业三年的人" |
| 性格特征 | "自带匪气的女人"、"天生反骨的人" |
| 处境描述 | "被家人拖累过的人"、"在体制内待过的人" |
| 反常标签 | 用社会认为"负面"的特质命名，反而引发共鸣 |

**注意：贴标签 ≠ 代入式权威**。

| ❌ 代入式权威（禁用） | ✅ 贴标签（可用） |
|---------------------|-----------------|
| 很多人都以为……其实…… | 自带"匪气"的女人 |
| 你是不是也……？ | 中年以后最聪明的活法 |
| 大多数人都会…… | 儿子"靠不住"的家庭 |

区别在于：贴标签直接命名那类人，不替读者预设心理活动、不扮演老师纠错。

### 情绪强度 8 种手法

| 手法 | 用法 | 注意 |
|------|------|------|
| 委屈感 | 写出不公平、不甘心、凭什么 | 要有真实处境 |
| 强否定 | 直接否定常见做法 | 正文必须给替代方案 |
| 自问答 | 用一句问答制造停顿 | 避免老师腔和说教感 |
| 激愤怒 | 表达强烈不爽或反感 | 只针对现象，不攻击读者 |
| 命中苦 | 说中具体烦恼 | 不替读者下诊断 |
| 情怀力 | 调动身份、经历、长期信念 | 避免空喊口号 |
| 造对立 | 制造选择或冲突 | 不制造无意义对立 |
| FOMO | 让读者担心错过窗口 | 必须有真实时效或机会差 |

### 小红书标题规则

1. 优先 16-18 字，最多不超过 20 字。
2. 关键词尽量前置，让算法和读者都能马上识别主题。
3. 标题可以用表情、分隔符、数字做停顿，但不要堆满。
4. 小红书标题的任务有两个：刺激点击 + 方便检索。
5. 题文必须统一，封面、标题、正文交付要说同一件事。

### 小红书实操公式

先选关键词，再选择公式，最后删减句子和补充轻量符号。

| 公式 | 模板 | 适合 |
|------|------|------|
| 省时省事 | `{数字/时间}+{关键词}+{结果}` | 教程、清单、提示词 |
| 实惠省钱 | `{关键词}+{省钱词}+{情绪}` | 工具替代、低成本方案 |
| 聚焦特征 | `{特征描述}+{问题/结果}` | 工具亮点、模型能力 |
| 解决问题 | `{使用场景}+{难题}+{方案}` | 真实卡点、踩坑解决 |
| 勾起情绪 | `{情绪词}+{出口}` | 观点、吐槽、强体验 |
| 运用数字 | `合集用大数 / 步骤用小数 / 序号做分割` | 合集、步骤、对比 |

小红书标题优化顺序：

1. 删掉虚词和解释性废话。
2. 把检索关键词放到前半句。
3. 加入一个具体数字、结果或场景。
4. 加入一个轻量情绪词或对话感。
5. 检查是否 16-18 字；超过 20 字优先删形容词。

### 强刺激生成公式

```
强刺激标题 = 具体关键词 + 信息密度手法 + 情绪强度手法 + 可兑现承诺
```

常用组合：

| 组合 | 适用 |
|------|------|
| 差异对比 + 强否定 | 反常识观点、工具替代旧方法 |
| 数字 + FOMO | 新工具、热点窗口、快速教程 |
| 情境错位 + 悬念 | AI 实验、案例复盘 |
| 对话场景 + 委屈感 | 真实经历、职场/创作踩坑 |
| 关键词公式 + 解决问题 | 小红书教程、清单、模板 |

### 输出标注格式

每个标题后面必须标注：

```
标题：xxx
劫持机制：预期违背 / 信息缺口 / 身份威胁 / 结果诱惑
信息密度：差异对比 / 情境错位 / 数字 / 悬念 / 热度 / 对话场景 / 视角代入 / 关键词公式
```

### 最后一道安全阀

如果标题强刺激，但正文只能交付 60%，不要删掉刺激感，先把标题降级到能兑现的强度。  
如果正文能交付 100%，可以大胆用狠版。

## 标题复盘训练卡

> 用于用户说"标题复盘"、"标题训练"、"帮我改旧标题"时。

### 训练目标

每次选择 3-5 篇旧文章或旧标题，每篇至少改 5 个标题。重点不是只给答案，而是写清楚为什么这样改，逐步沉淀自己的标题手感。

### 复盘表字段

| 字段 | 写法 |
|------|------|
| 原标题 | 原样记录 |
| 原标题问题 | 太像概括 / 缺情绪 / 缺数字 / 缺冲突 / 关键词弱 / 承诺不清 |
| 改写标题 | 给出新标题 |
| 改写方向 | 信息密度 / 情绪强度 / 小红书检索 / 公众号冲突 / 克制清楚 |
| 使用手法 | 差异对比、情境错位、数字、悬念、热度、对话场景、视角代入、关键词公式等 |
| 情绪钩子 | 委屈感、强否定、自问答、激愤怒、命中苦、情怀力、造对立、FOMO |
| 兑现风险 | 已支撑 / 需要补案例 / 需要降级表达 |

### 每篇文章的 5 个改写方向

1. **信息密度版**：增加具体数字、对象、场景或反差。
2. **情绪强度版**：增加不甘心、否定、焦虑、惊讶、爽感或冲突。
3. **小红书检索版**：关键词前置，16-18 字优先。
4. **公众号冲突版**：放大观点、悬念或对立，允许更长。
5. **克制清楚版**：降低刺激，但提高承诺清晰度。

### 最终沉淀

如果某类改法连续 3 次效果更好，记录到 `skills/_通用/风格档案/反馈记录.md` 或数据复盘中，后续标题优先使用。

## 数据复盘更新

> 2026-03-10 数据复盘补充

### 新增公式：实操教程型

**公式**：`[工具名] 从入门到[结果]，我花[时间]替你跑通了。直接抄。`

**数据验证**：Seedance 2.0 文章 31K 阅读，收藏率 22.7%。

**适用场景**：
- 新工具 / 新功能发布 7 天内，仍处在热点窗口期
- 有真实实操案例
- 提供可直接复制的内容，比如提示词、清单、步骤

**示例**：
- Seedance 2.0 从入门到出片，我花一天替你跑通了。直接抄。
- Cursor 到底怎么玩？我花一天扒完了所有技巧

### 禁用公式：过度自信型

| 公式 | 翻车原因 | 数据 |
|------|---------|------|
| 所有人都在[做X]，没人注意到[Y] | 过于自信，读者不关心 | 170阅读（最低） |

**建议**：避免使用”所有人都在...”这类过于自信的表达。

## 标题劫持检验（生成后必做）

> 详见 [`cognitive-hijack-checklist.md`](cognitive-hijack-checklist.md)

### 核心原则

标题的任务不是描述内容，是**打断注意力**。如果读者看完标题没有认知冲突，标题就是废的。

### 生成流程

1. **提取一句话洞察**：从正文里找到最反常识 / 最有价值的一句结论
2. **选择马斯洛元素**：用 3-4 个元素包装洞察（必含”视觉”或”成本”）
3. **套用劫持机制**：预期违背 / 信息缺口 / 身份威胁 / 结果诱惑，至少命中 1 种
4. **生成标题变体**：按 7 种公式 + 常规狠版生成
5. **逐条检验**：过 4 项自检（认知冲突 / 元素命中 / 人性触发 / 3秒测试），不通过的淘汰

### 快速淘汰清单

- 只说”是什么”的描述性标题 → 淘汰
- 像功能介绍 / 产品说明书的标题 → 淘汰
- 命中马斯洛元素 < 3 个 → 淘汰或补强
- 4 种劫持机制一个都没命中 → 淘汰
- 想象刷手机看到它，不会停下来 → 淘汰
