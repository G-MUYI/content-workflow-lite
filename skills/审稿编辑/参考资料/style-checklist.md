# 风格检测清单

## 本人的写作风格特征

基于真实写作样本提炼，用于检测文章是否符合人设。

---

## 一、语气特征（必须有）

### 1.1 口语化表达

| ✅ 符合风格 | ❌ 不符合风格 |
|------------|--------------|
| 我寻思着 | 我认为 |
| 这事儿能难住我吗？ | 这个问题不难解决 |
| 你懂吧 | 您理解吗 |
| emmm | 嗯 |
| 哈哈 / 哈哈~ | （没有轻松表达） |
| 我整个人都兴奋起来了 | 效果非常好 |
| 这不就是...了嘛 | 这是一个很好的机会 |
| 懂的都懂 | 大家都明白 |

> 2026-05-08 修订：剔除"真的，太帅了 / 离谱"两条引文，原引文来自非本人作品。完整风格基线见 `skills/_通用/风格档案/我的风格.md`。

### 1.2 波浪号使用

**结尾常用**：
- "好了，今天的分享就到这儿啦~"
- "感兴趣的朋友可以玩起来啦~"

**语气词常用**：
- "完全免费！！完全免费！！完全免费！！"
- "重要的事情说三遍~"

### 1.3 省略号节奏

**用于制造悬念或停顿**：
- "然后就一边耗着，一边焦虑..."
- "结果合作越做越别扭，内容也干不出来..."

## 二、真实性与作者在场（按相关性选用）

以下特征是历史样本中出现过的写法，不是数量配额。只有直接服务当前主题和读者判断时才保留。

### 2.1 具体数字

| 类型 | 示例 |
|------|------|
| 金额 | "变现3000+"、"3天赚3000" |
| 粉丝/流量 | "公众号2300+"、"引流600+" |
| 时间 | "搞了小半年"、"坚持了大半年" |
| 次数 | "搞了好多遍才成功"、"试了N个" |

### 2.2 时间线索

| 类型 | 示例 |
|------|------|
| 具体时间 | "前两天"、"上周"、"去年"、"2023下半年" |
| 相对时间 | "最近"、"刚刚"、"昨天晚上" |
| 持续时间 | "坚持了大半年"、"做了一个月" |

### 2.3 相关时说明局限

| 类型 | 示例 |
|------|------|
| 承认失败 | "一开始聚焦AI提示词,个位数的阅读量让我很沮丧" |
| 承认折腾 | "我也是搞了好多遍，才成功" |
| 承认不完美 | "不过影响不大，后期把失真的音频片段剪切掉" |
| 承认不懂 | "但是这个明星我还是没听出来是谁" |

## 三、结构特征

### 3.1 开头模式

**好的开头不只一种**：数字/结果、具体动作、具体物件、直接判断、真实问题、产品功能、对比结果、复盘反思都可以，关键是服务文章承诺。

**真实故事/场景示例**：
```
前两天,有个粉丝在后台问我:"你知道怎么克隆一个明星的声音吗?"
```

```
上个月我删掉了一篇写了三天的稿子。
```

**弱的开头（直接说主题）**：
```
最近我发现了一个很厉害的AI工具，想跟大家分享一下。
```

**公式化开头（直接判失败）**：

- “今天整理素材的时候，我刷到……”
- “真正让我停下来看的，是……的差别 / 区别”
- 与最近 5 篇同时重复“来源动作 + 句式骨架”，只是替换工具名或主题词

审稿时读取最近 5 篇 `drafted` 及以上正文开头，比较“对象 + 动作 + 句式”指纹。撞型时要求换开头原型，不能只做同义词改写。

### 3.2 结尾模式

**标准结尾**：
```
好了，今天的分享就到这儿啦~
感兴趣的朋友可以玩起来啦~
```

**互动引导**：
```
有知道的朋友可以评论区留言。
```

**引流钩子**：
```
地址在这里：[链接]
```

### 3.3 转折和吐槽

**常用转折**：
- "不过好在..."
- "但是..."
- "话说回来..."

**常用吐槽**：
- "这不就是给我们这些搞创作的送了个大礼包吗?"
- "这事儿能难住我吗？"
- "我整个人都兴奋起来了"

## 四、禁止出现

> 说教感、官方腔、AI味、互联网黑话的完整禁用清单见 [`../../_通用/写作约束.md`](../../_通用/写作约束.md)

### 伪真实检测

不要因为全文没有失败、折腾或局限就要求补充。先检查作者是否夸大亲历或实测，再检查已有作者侧信息是否与主题相关。

**检测信号**：
- 为了显得真实，突然插入与主题无关的失败或折腾
- 把浏览器登录、自动化停止、Agent/Skill 调用写进正文
- 连续罗列"没部署 / 没运行 / 没复算"，但正文并不依赖这些结论
- 全文只堆资料，没有作者的选择、判断或筛选标准

## 五、风格自检问题

写完后问自己：

1. **这句话我会在饭桌上这么说吗？**
   - 会 → 保留
   - 不会 → 改掉

2. **这段话读起来像官方通稿吗？**
   - 像 → 重写
   - 不像 → 保留

3. **读者能感受到"这是一个真人在跟我聊天"吗？**
   - 能 → OK
   - 不能 → 补与主题相关的选择或判断，不按数量添加口头禅

4. **有没有让读者觉得"这人怎么这么懂我"的点？**
   - 有 → OK
   - 没有 → 加点共鸣点

5. **开头是否把整理素材、浏览来源或自动任务取材写成事件？**
   - 是 → 删除内部过程，直接写对象、结果或判断

6. **开头是否和最近 5 篇撞型？**
   - 是 → 换开头原型
