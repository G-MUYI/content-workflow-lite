# 视频生成器 (Video Maker)

> **Role**: 内容提取 & 视频数据结构化
> **核心能力**: 从选题文件提取关键内容 → 结构化为视频 JSON → 调用 Remotion 渲染
> **前置依赖**:
> - `../_通用/爆款核心定义.md`
> - `../Remotion最佳实践/SKILL.md`（修改视频代码时参考）

---

> 协作边界：自主选择、澄清、批准和完成统一按 `../../AGENTS.md` 的“自主执行、澄清与完成”；下文步骤不构成逐步审批，职责切换由当前 Agent 完成。

## 工作流 (Workflow)

### 步骤 1：确定选题文件

- 如果用户指定了选题 → 直接读取对应文件
- 如果未指定 → 按以下优先级自动选择：
  1. 优先当前会话明确处理的文章；否则 `选题库/进行中/` 中 `stage` 为 `drafted` 及以上的最新文件
  2. 若进行中目录无匹配，则从 `选题库/待写/` 中选 `stage: planned` 的最新文件
- **最低阶段要求**：`planned`（至少要有内容结构）
- `planned` 仅支持基于已有事实的内容转述；教程、对比效果或实测声明仍需真实测试证据。不能借视频分支绕过实测门禁，也不能未经用户同意把实测视频改成交付预期效果的演示。

### 步骤 2：内容提取 (Content Extraction)

从选题文件中提取三个核心要素：

| 要素 | 提取来源（按优先级） | 说明 |
|------|---------------------|------|
| **title** | YAML `title` 字段 | 视频标题 |
| **coreInsight** | `## 选题评估` > `### 核心洞见` | 一句话核心观点 |
| **sections** | `## 正文`（优先）或 `## 内容策划` > `### 内容结构` | 视频分段内容 |

**sections 提取规则**：

- 从 `## 正文` 提取（drafted 及之后）：
  - 每个 `###` 标题 → 一个 section.title
  - 该标题下的要点/段落 → section.points（每条不超过 30 字）
  - 过长的段落需压缩为要点

- 从 `## 内容策划 > ### 内容结构` 提取（planned 阶段）：
  - 大纲中的每个段落标题 → section.title
  - 段落下的要点 → section.points

### 步骤 3：数据结构化 (Data Structuring)

输出符合 `ArticleVideoProps` 的 JSON：

```json
{
  "title": "视频标题",
  "coreInsight": "一句话核心洞见",
  "sections": [
    {
      "title": "段落标题",
      "points": ["要点1", "要点2", "要点3"]
    }
  ]
}
```

**约束**：
- sections 数量：3~6 个（太少没内容，太多视频太长）
- 每个 section 的 points：2~4 条
- 每条 point 不超过 30 字（屏幕显示限制）
- 总时长估算：标题 3s + 洞见 5s + 每段 6.6s ≈ 控制在 60s 以内

### 步骤 4：保存 & 渲染

1. **保存 JSON**：写入 `视频生成器/props/<选题名>.json`
2. **执行渲染**：
   ```bash
   cd 视频生成器 && npx remotion render ArticleVideo --props="props/<文件名>.json" "out/<选题名>.mp4"
   ```
3. **回写选题文件**：在原选题文件 `## 分发素材` > `### 视频` 中写入 Props 路径、视频路径和素材缺口。
4. **验证交付**：等待渲染完成，确认 MP4 存在、可读取、时长与内容符合请求，并检查关键帧；通过后展示输出路径。只有 JSON 或预览启动时不能称视频完成，渲染失败先修复本地可处理问题。

**预览模式**（不渲染，只预览）：
```bash
cd 视频生成器 && npx remotion studio
```
提示用户在 Studio 中选择 ArticleVideo，手动加载 props 预览。

## 交互示例

**用户输入**：
> "生成视频"（当前有一篇 drafted 的文章《别学Skills了，先把提示词写好》）

**执行流程**：
1. 读取 `选题库/进行中/S级-意外-别学Skills了先把提示词写好.md`
2. 提取 title / coreInsight / sections
3. 保存到 `视频生成器/props/别学Skills了先把提示词写好.json`
4. 运行 Remotion 渲染
5. 输出：`视频生成器/out/别学Skills了先把提示词写好.mp4`

## 技术约束

1. **复用组件**：常规任务优先只生成 JSON；渲染缺陷或用户要求的效果确需改代码时，可在本项目做最小必要修复并按需读取 Remotion 规则，不另建生成器
2. **中文文件名**：JSON 文件名用选题标题（去掉特殊字符），渲染命令中用双引号包裹
3. **视频规格**：1920×1080，30fps（由 Root.tsx 中的 Composition 定义）
4. **修改视频模板时**：先读取 `skills/Remotion最佳实践/SKILL.md` 获取 Remotion 编码规范
