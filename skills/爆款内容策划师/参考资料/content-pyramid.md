# 内容逻辑金字塔详解

## 核心原则

> **大多数人做内容是死胡同，因为顺序反了。**

正确顺序：**洞察 → 钩子 → 实证 → 交付**

错误顺序：先想标题 → 再想内容 → 最后硬凑观点

---

## 第一层：一句话洞察 (The Insight)

### 定义

所有内容的起点。是你最想传递的：
- 核心观点
- 反常识发现
- 解决方案

### 好洞察的标准

| 标准 | 说明 | 示例 |
|------|------|------|
| **反常识** | 颠覆大众认知 | "做内容，拼的是谁能更低成本地获取信任，不是谁文笔更花" |
| **扎心** | 戳中隐藏痛点 | "老板真正缺的，是能像使鼠标一样使AI的员工" |
| **可证明** | 能用Demo佐证 | "设计师学AI编程比程序员快，因为更懂需求" |

### 坏洞察的特征

| 特征 | 示例 | 问题 |
|------|------|------|
| 太温吞 | "AI很有用" | 没有让人停下来的理由 |
| 太泛泛 | "学会AI能提效" | 谁都知道，没有信息增量 |
| 无法证明 | "AI会改变世界" | 空对空，没有实证 |

### 挖掘洞察的问题清单

1. 关于这件事，你最想打脸谁的观点？
2. 你发现了什么别人不知道的真相？
3. 你能证明什么反常识的事？
4. 你做成了什么别人做不到的事？
5. 主流做法哪里"蠢"？

---

## 第二层：量身打造钩子 (The Hook)

### 定义

基于洞察，利用"马斯洛13元素"将其包装成 **3秒内无法拒绝的诱饵**。

### 钩子公式

```
钩子 = 洞察 + 马斯洛元素包装

【洞察】设计师学AI编程比程序员快
    ↓ 加入 [成本] + [视觉] + [反向]
【钩子】"我裁掉了月薪3万的程序员，让设计师用AI写代码"
```

### 钩子检查清单

- [ ] 3秒内能抓住注意力吗？
- [ ] 命中了至少3-4个马斯洛元素吗？
- [ ] 必须包含"视觉"或"成本"吗？
- [ ] 和洞察一致吗？（不是标题党）

---

## 第三层：视觉实证 (The Proof)

### 定义

也叫 **Spec Work**。用你的技能做出Demo，证明你的洞察不是空话。

### 为什么必须有实证？

| 没有实证 | 有实证 |
|---------|--------|
| "AI能3分钟做海报" (吹牛) | 录屏：从0到成品只用了2分47秒 |
| "设计师学编程很快" (空话) | 展示：我一周做出的自动化脚本 |
| "这个工具很厉害" (推销) | 对比：左边传统方法3小时，右边10分钟 |

### 实证类型

| 类型 | 适用场景 | 示例 |
|------|---------|------|
| **实操录屏** | 流程演示 | 从草图到成品的全程录屏 |
| **前后对比** | 效果展示 | 左边原图，右边AI处理后 |
| **数据截图** | 效率证明 | 时间记录、产出数量对比 |
| **作品展示** | 能力证明 | 用AI做的实际项目作品集 |
| **失败案例** | 避坑分享 | 踩坑过程的真实记录 |

### 实证规划模板

```
🛠️ 必须手动制作的实战案例

素材哪里找：
- [具体获取路径]

你要做什么：
- [具体任务描述]
- [预计耗时]

预期效果：
- [这个Demo如何佐证你的"一句话洞察"？]
```

## 第四层：简单交付 (The Delivery)

### 定义

用最简单的结构讲清楚，**不炫技，只交付价值**。

### 交付结构

```
【钩子 Hook】3秒
抛出问题或结论

【承接 Bridge】10秒
快速引出"一句话洞察"

【展示 Demo】主体
播放Spec Work，边看边讲，用事实说话

【交付 Value】收尾
简单的分点/对比总结，让观众觉得"学到了"
```

### 交付原则

| 原则 | 说明 |
|------|------|
| **简单** | 3-5个要点，不要堆砌 |
| **可执行** | 观众看完能立刻行动 |
| **有获得感** | 让人觉得"学到了"/"值了" |

---

## 完整案例

### 洞察
> "老板真正缺的，是能像使鼠标一样使AI的员工"

### 钩子
> [成本] + [视觉] + [人群]
> "我用AI取代了公司的设计外包，老板给我涨薪50%"

### 实证
> 录屏：展示从甲方需求到AI生成全套VI只用15分钟的全过程

### 交付
> 1. 如何用AI理解需求（提示词模板）
> 2. 如何批量生成方案（工作流）
> 3. 如何快速迭代修改（对话技巧）
