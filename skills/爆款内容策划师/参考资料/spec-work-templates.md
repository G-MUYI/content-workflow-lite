# 派活清单模板 (Spec Work Templates)

> 策划师在 Step 2 生成策划方向时，必须根据内容类型选择对应模板，输出具体的派活清单。

---

## 通用派活结构

每个策划方向必须包含以下派活清单：

```
🛠️ 派活清单 (你需要手动准备的素材)

① 截图清单
   - [ ] [在哪截] → [截什么] → [证明什么]
   - [ ] ...

② 录屏/操作任务
   - [ ] [具体做什么] → [预期时长]
   - [ ] ...

③ 提示词准备
   - [ ] [提示词内容] → [用在哪个步骤]
   - [ ] ...

④ 对比素材
   - [ ] [对比项] → [素材来源]
   - [ ] ...

💡 为什么要做这些: [这些素材如何支撑文章可信度]
```

## 按内容类型的派活模板

### 1. 教程类（学习复现型）

> 核心：读者能跟着做。每一步都要有截图 + 提示词。

**派活重点：提示词序列 + 每步截图 + 预期结果**

```
🛠️ 派活清单

   │ 如果结果不对：[调整建议]                │
   ├─────────────────────────────────────┤
   │ 步骤2 - [步骤名称]                    │
   │ 提示词：                              │
   │ "[完整的提示词内容]"                    │
   │                                       │
   │ 预期结果：[描述]                       │
```

### AI 绘图提示词模板

必须把以下信息写进一条完整提示词。平台没有独立负面提示词输入框时，把禁止项写进主提示词末尾。

```text
请生成一张[用途]图片。

主体：[人物、产品或物体的明确描述]
动作与状态：[具体动作、姿势、表情或产品状态]
场景：[地点、背景元素、前中后景]
构图：[景别、主体位置、留白、视角]
画风：[媒介、质感、线条或渲染方式]
光线：[时间、光源方向、明暗关系]
配色：[主色、辅助色、需要避免的颜色]
画面比例：[比例]

必须保持不变：
- [角色脸部、发型、服装、产品结构等锚点]
- [本轮所有结果都要固定的条件]

本轮只测试：
- [唯一变量]

禁止出现：
- [多余手指、肢体变形、文字乱码、角色换装等]
- [与文章结论相关的失败项]

预期结果：
[一段可以直接对照验收的结果描述]
```

如为角色一致性测试，至少准备两轮：

- A 组：只使用设定图，其他参数固定
- B 组：使用设定图加风格校准图，其他参数固定

```text
参考素材：[首帧、尾帧、角色图或产品图的用途]

必须保持稳定：
- [人物脸、服装、产品结构、背景连续性]
- [镜头或运动中不能漂移的元素]

本轮只测试：
- [唯一变量]

禁止出现：
- [闪烁、跳帧、人物变形、物体穿模、镜头瞬移]

[描述每个时间段应该看到的内容和最终停留画面]
```

视频截图除了通用清单，还要增加：

- [ ] 尾帧 → 证明收尾是否符合提示词
- [ ] 时间线或关键帧设置 → 证明镜头和动作参数
- [ ] 异常帧 → 证明闪烁、变形或穿模问题

## 派活清单检查规则

策划师输出派活清单后，必须自检：

| 检查项 | 标准 |
|--------|------|
| 截图清单是否具体到界面和区域 | 不能只写"截个图"，要写"在XX界面截取XX区域" |
| 提示词是否可直接复制使用 | 不能只写"写个提示词"，要给出完整内容 |
| 每个素材是否标注了用途 | 每条素材都要说明"证明什么"或"用在哪里" |
| 素材来源是否明确 | 要告诉用户去哪里找素材 |
| 是否有至少1个视觉实证 | 没有视觉素材的方案不允许输出 |
