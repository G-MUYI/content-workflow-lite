# 写作框架详解

## 模式一：故事化写作框架（5步）

### 第一步：情绪锚定（开篇）⭐最重要

**这是整篇文章最重要的部分。**

- 讲述一个与主题相关的个人故事，或大家都经历过的糟心事
- 故事要**具体、有画面感**，能唤起读者的共同记忆
- 可以是：一个场景、一段对话、一个让你触动的瞬间、一个大家都经历过的困境

**开篇示例：**

**示例1：踩坑型开头**
```
上周我花了整整两天写了一篇稿子。
标题改了七八遍，开头删了重写三次，自认为干货满满。
结果发出去...阅读量47。
那感觉你懂吧，就像自己精心准备了一桌菜，结果客人筷子都没动就走了。
```

**示例2：场景对话型开头**
```
前两天有个粉丝私信我：你那个AI写作的流程能教我吗？
我说可以啊，然后噼里啪啦发了一堆截图给他。
结果他回了一句：太复杂了，看不懂...
那一刻我突然意识到，我一直以为自己讲得很清楚，其实别人根本听不进去。
```

**示例3：发现型开头**
```
昨天晚上刷到一个帖子，博主说他用Cursor写了一套自动化工作流，3天涨了5000粉。
我寻思着，这不就是我一直想做的事吗？
然后我就开始折腾了...
真的，一折腾就停不下来。
```

**示例4：反常识型开头**
```
现在回头看，我成长最快的几个阶段，几乎都是从换方向开始的。
换工具、换圈子、换做事的方法。
```

### 第二步：借势增信（过渡）

- 提到一位相关领域大佬说过的话或观点
- 或者引用一个大家都认可的现象、趋势、数据
- 目的：**降低读者的怀疑成本**，让他们觉得"嗯这事儿有道理"

### 第三步：价值交付（核心）

- 给出真正要分享的干货、方法、工具、观点
- 拆解要具体，**让普通中学生都能看懂**

### 第四步：伤疤共情（深化）

- 分享你自己用这个方法的真实经历（有就写，没有不补编）
- 与主题和结论相关的坑、错和弯路可以直接讲

**注意**：不要为显得真实硬塞糗事。相关时如实讲，无关时不提。

### 第五步：哲学升华（收尾）

- 用一句老话、名人名言或有分量的观点作结
- 把实操的事儿**拉到人生感悟的层面**
- 收尾不必套固定句，按本人结尾模式选择

## 模式二：教程写作框架

### 第一步：痛点开场（故事化）

不要直接说"今天教大家xxx"，而是：
- 用一个场景引入
- 说明为什么需要学这个
- 让读者觉得"这正是我需要的"

```
上周有个朋友问我：你那个AI生成的图是怎么做的？
我花了10分钟教他，他当场就做出来了。
今天我把这个方法整理出来，你跟着做，10分钟也能学会。
```

### 第二步：效果展示

先展示最终效果，让读者有期待感。
`📸 【截图位置】最终效果图`

### 第三步：工具/准备

列出需要的工具和准备工作。

### 第三步：分步教学

**每一步都要包含：**
1. **做什么**（动作）
2. **怎么做**（具体操作）
3. **截图标注**（需要截图的地方）
4. **实操提示**（需要验证的地方）

### 第四步：常见问题

列出新手可能遇到的问题和解决方案。

### 第五步：总结 + 引导

总结关键步骤，引导互动。
**最后加一句：好了，今天的分享就到这儿了**
