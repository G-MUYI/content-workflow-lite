# 会话持久化与反馈学习使用指南

> 如何使用新增的会话记忆、用户偏好和反馈学习功能

---

## 一、会话持久化

### 功能说明

会话持久化让 AI 能够跨对话记住上下文，即使中断对话后重新开始，也能无缝恢复。

### 自动触发

每次对话开始时，AI 会自动：
1. 读取 `会话记忆.md`，恢复未完成的任务
2. 读取 `用户偏好.md`，了解你的偏好
3. 在仪表盘顶部显示中断的任务

### 手动触发

| 你说 | AI 做什么 |
|------|----------|
| "上次说到哪了" | 读取会话记忆，告诉你上次的进度 |
| "继续上次的" | 从上次中断的地方继续 |
| "记住这个任务" | 将当前任务记录到会话记忆 |

### 使用场景

**场景 1：任务中断**
```
你：我要写一篇关于 AI 工具的文章，先帮我策划大纲
AI：[生成大纲]
你：好的，我先去吃饭，等会再写
AI：[自动记录到会话记忆：当前任务 = 写 AI 工具文章，已完成策划]

--- 下次对话 ---

AI：[自动读取会话记忆]
    🔄 上次中断的任务
    ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
    · 写 AI 工具文章 — 已完成策划 — 下一步: 说"写"开始写作

你：继续
AI：好的，现在开始写作...
```

**场景 2：临时偏好**
```
你：这次我想写得更轻松一点，不要太正式
AI：[记录到会话记忆 > 临时偏好]
    好的，这次会用更轻松的语气。

--- 写作过程中 ---

AI：[参考临时偏好，使用更口语化的表达]

--- 任务完成后 ---

AI：[自动清理临时偏好]
```

## 二、用户偏好追踪

### 功能说明

用户偏好追踪记录你的长期偏好，包括语言风格、工作习惯、情绪模式等。

### 自动学习

AI 会自动识别你的偏好：
- 你多次修改同类内容 → 识别为偏好模式
- 你明确表达喜好 → 立即记录
- 你的情绪状态变化 → 动态调整回复方式

### 手动更新

| 你说 | AI 做什么 |
|------|----------|
| "记住这个偏好" + [说明] | 立即更新到用户偏好档案 |
| "我不喜欢xxx" | 记录到偏好档案 |
| "以后都这样" | 将当前方式记录为偏好 |

### 使用场景

**场景 1：明确表达偏好**
```
你：我不喜欢"综上所述"这种表达，太正式了
AI：[立即更新到用户偏好 > 语言风格偏好]
    好的，已记住。以后会避免使用"综上所述"。
```

**场景 2：情绪识别**
```
你：快点，直接说结论
AI：[识别情绪 = 焦虑/急躁]
    [更新用户偏好 > 当前情绪状态]
    [调整回复策略 = 极简回复，只给结论]

    结论：xxx
```

**场景 3：工作习惯**
```
你：[连续 3 次要求分步推进]
AI：[识别模式 = 偏好分步推进]
    [更新用户偏好 > 工作习惯]

    注意到你喜欢分步推进，以后会在每步完成后等你确认。
```

## 三、反馈学习机制

### 功能说明

反馈学习让 AI 从你的修改中学习，逐步调整生成风格以匹配你的习惯。

### 自动学习

AI 会自动识别你的修改：
- 你修改了 AI 生成的内容 → 对比差异，记录模式
- 你说"不对"后重新生成 → 记录第一次的问题
- 你多次要求重写 → 识别不满意的原因

### 手动触发

| 你说 | AI 做什么 |
|------|----------|
| "记录这次反馈" | 分析你的修改，记录到反馈记录 |
| "学习我的修改" | 对比原文和修改后的版本，提取模式 |
| "为什么我改成这样" | 分析修改原因，更新风格档案 |

### 使用场景

**场景 1：词汇替换**
```
AI：综上所述，这个方案可行。
你：[修改为] 好了，这个方案可行。

AI：[自动识别修改]
    [记录到反馈记录：词汇替换 - "综上所述" → "好了"]
    [累积 1 次]

--- 第 3 次同类修改后 ---

AI：[达到阈值，自动更新风格档案]
    📝 已学习到你的偏好：
    · 禁用词：综上所述
    · 替代词：好了

    以后会自动使用"好了"代替"综上所述"。
```

**场景 2：句式调整**
```
AI：这个工具非常强大，它可以帮助你快速完成任务，而且操作简单。
你：[修改为] 这个工具很强大。可以帮你快速完成任务。操作也简单。

AI：[识别修改模式 = 长句拆短句]
    [记录到反馈记录：句式调整 - 长句拆短句]

你：记录这次反馈
AI：📝 反馈已记录

    修改类型：句式调整
    修改内容：
      AI 输出：长句（30+ 字）
      你的修改：拆成 3 个短句（10 字左右）

    分析原因：你偏好短句，节奏更快

    学习结果：
      ✅ 已记录到反馈记录（累积 1 次）

    💡 提示：再有 2 次同类修改，将自动更新到风格档案
```

**场景 3：语气修改**
```
AI：今天的分享就到这里。
你：[修改为] 好了，今天的分享就到这儿啦~

AI：[识别修改]
    [词汇："这里" → "这儿"]
    [语气："。" → "~"]
    [开头：无 → "好了，"]

    [记录到反馈记录]
```

## 四、学习阈值与更新规则

### 累积阈值

| 修改类型 | 阈值 | 说明 |
|---------|------|------|
| 词汇替换 | 3 次 | 同一个词被替换 3 次 → 更新风格档案 |
| 句式调整 | 3 次 | 同类句式调整 3 次 → 更新风格档案 |
| 语气修改 | 3 次 | 同类语气修改 3 次 → 更新风格档案 |
| 明确指令 | 1 次 | 你说"记住这个" → 立即更新 |

### 更新位置

| 修改类型 | 更新文件 |
|---------|---------|
| 词汇、句式、语气 | `风格档案/我的风格.md` |
| 协作偏好、反馈习惯 | `用户偏好.md` |
| 临时性偏好 | `会话记忆.md` |

### 冲突处理

当新偏好与旧偏好冲突时：
1. AI 会询问："之前你说 xxx，现在说 xxx，以哪个为准？"
2. 你确认后，AI 更新偏好并记录变更

## 五、最佳实践

### 1. 主动表达偏好

不要等 AI 猜，直接说：
- "我不喜欢这种表达"
- "以后都用这种方式"
- "记住这个偏好"

### 2. 及时反馈

发现 AI 输出不符合预期时：
- 说"不对"并说明原因
- 修改后说"记录这次反馈"
- 不要默默修改，让 AI 学习

### 3. 定期回顾

每月回顾一次：
- 查看 `用户偏好.md`，确认是否准确
- 查看 `反馈记录.md`，看看积累了哪些模式
- 查看 `风格档案/我的风格.md` 的“更新记录”，了解风格变化

### 4. 清理过期信息

- 任务完成后，确认 AI 清理了会话记忆
- 临时偏好不再适用时，主动说"取消这个偏好"
- 过期的反馈记录定期清理

## 六、常见问题

### Q1：AI 会自动学习所有修改吗？

不会。AI 只记录修改，累积到阈值（3 次）才更新到风格档案。如果你希望立即生效，说"记住这个"。

### Q2：如果我的偏好变了怎么办？

直接说新的偏好，AI 会询问是否覆盖旧偏好。确认后会更新并记录到变更记录。

### Q3：会话记忆会一直保留吗？

不会。任务完成后会自动清理。只保留最近 3 次对话的关键决策。

### Q4：如何查看当前的偏好设置？

说"查看我的偏好"或"风格档案状态"，AI 会展示当前的偏好和风格档案。

### Q5：可以关闭自动学习吗？

可以。说"暂停自动学习"，AI 会停止自动记录修改。需要时说"恢复自动学习"。

## 八、快速开始

### 第一次使用

1. **初始化风格档案**
   ```
   你：学习我的风格 + [发几篇你的历史文章]
   AI：[提取风格特征，生成风格档案]
   ```

2. **设置基本偏好**
   ```
   你：记住这些偏好：
       - 我喜欢简短直接的回复
       - 不要用"综上所述"这种表达
       - 重要决策必须确认
   AI：[记录到用户偏好]
   ```

3. **开始使用**
   ```
   你：[正常使用工作流]
   AI：[自动学习你的修改和偏好]
   ```

### 日常使用

- 正常对话，AI 会自动记忆和学习
- 发现不对时，说"不对"并说明原因
- 任务中断时，AI 会自动记录，下次继续

### 定期维护

- 每月查看一次偏好档案
- 清理过期的会话记忆
- 回顾反馈记录，确认学习效果
