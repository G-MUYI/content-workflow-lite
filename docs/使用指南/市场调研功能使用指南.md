# 市场调研功能使用指南

## 功能概述

市场调研功能由知识园丁负责，通过联网搜索分析外部市场内容，帮助你：
- 了解竞品内容的角度和结构
- 识别差异化机会
- 提取用户真实痛点
- 追踪热点趋势

## 使用场景

### 1. 选题阶段（可选）
**目的**：判断选题是否值得写

```
用户：市场调研
AI：调用知识园丁，搜索相关内容，分析市场饱和度
```

**适用情况**：
- 不确定这个话题是否有人写过
- 想了解市场竞争情况
- 需要验证选题价值

### 2. 策划阶段（推荐）
**目的**：为内容策划提供外部参考

```
用户：策划
AI：检查是否已有市场调研
  → 如果没有，询问"要先做市场调研吗？"
  → 用户确认后执行调研
  → 调研完成后进入策划
```

**适用情况**：
- 需要了解竞品的写作角度
- 想找到差异化切入点
- 需要补充案例和素材

## 调研报告内容

市场调研会生成以下内容，保存到选题文件的 `## 市场调研` 区块：

### 1. 竞品分析
- 3-5 篇高质量竞品内容
- 每篇标注：切入角度、内容结构
- 示例：
  ```
  1. [如何用 AI 提升写作效率](链接)
     角度：工具推荐 + 实战案例
     结构：痛点 → 工具介绍 → 使用步骤 → 效果展示
  ```

### 2. 差异化机会
- 角度空白：哪些角度还没人讲？
- 深度不足：哪些内容讲得不够深？
- 新鲜案例：有没有新的工具/产品/案例可以用？

### 3. 用户痛点
- 从评论区、问答区提取用户真实问题
- 识别高频痛点和未被解决的需求

### 4. 热点趋势
- 最近 1 个月的相关热点
- 新出现的工具/产品
- 用户讨论的新话题

## 使用技巧

### 1. 何时跳过调研
- 纯个人经历类内容（独特性强）
- 时效性极强的内容（来不及调研）
- 已经非常了解市场情况

### 2. 如何利用调研结果
- **避免重复**：如果发现已有大量类似内容，考虑换角度或放弃
- **找差异化**：重点关注"差异化机会"部分，找到独特切入点
- **补充素材**：从竞品中学习好的案例和表达方式
- **回应痛点**：确保内容能解决用户真实痛点

### 3. 调研后的决策
- **继续策划**：找到差异化角度，有信心写出更好的内容
- **调整选题**：发现市场饱和，调整选题方向
- **放弃选题**：市场已饱和且无差异化空间

## 快捷指令

| 指令 | 说明 |
|------|------|
| "市场调研" | 对当前选题执行市场调研 |
| "看看别人怎么写" | 同上 |
| "策划" | 进入策划前会询问是否需要调研 |

## 注意事项

1. **调研不是抄袭**：调研是为了找差异化，不是照搬竞品
2. **调研结果仅供参考**：最终内容质量取决于你的独特视角和真实作品
3. **调研需要时间**：联网搜索和分析需要 1-2 分钟，请耐心等待
4. **调研结果会保存**：调研报告会写入选题文件，下次可以直接查看

## 示例流程

### 完整流程（含调研）
```
1. 用户投喂素材 → 选题大师生成选题
2. 用户确认选题 → 选题入库（checked_in）
3. 用户说"策划" → AI 询问"要先做市场调研吗？"
4. 用户确认 → 知识园丁执行调研（market_researched）
5. 调研完成 → 内容策划师开始策划（strategies_generated）
```

### 快速流程（跳过调研）
```
1. 用户投喂素材 → 选题大师生成选题
2. 用户确认选题 → 选题入库（checked_in）
3. 用户说"策划" → AI 询问"要先做市场调研吗？"
4. 用户说"不用" → 直接进入策划（strategies_generated）
```

## 常见问题

**Q: 每个选题都需要做市场调研吗？**
A: 不需要。纯个人经历、独特视角的内容可以跳过。调研主要用于竞争激烈的话题。

**Q: 调研结果不准确怎么办？**
A: 调研结果仅供参考，最终决策权在你。如果觉得不准确，可以忽略或手动补充。

**Q: 可以只做调研不策划吗？**
A: 可以。直接说"市场调研"即可，不会自动进入策划。

**Q: 调研后发现市场饱和，怎么办？**
A: 可以选择：(1) 调整选题角度，(2) 放弃选题，(3) 用更强的作品支撑强行突围。
