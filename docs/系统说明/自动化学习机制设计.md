# 自动化学习机制设计

> 完全无感的后台自动化学习系统

---

## 设计原则

### 核心理念

**"学习应该是无感的"** - 用户不需要主动触发，AI 在后台自动观察、记录、学习。

### 三个自动化层级

| 层级 | 触发方式 | 用户感知 | 示例 |
|------|---------|---------|------|
| **静默学习** | 完全自动，不提示 | 无感知 | 记录修改模式、识别情绪 |
| **提示确认** | 自动识别，询问确认 | 轻度感知 | "注意到你喜欢短句，要记住吗？" |
| **主动触发** | 用户明确要求 | 完全感知 | "记住这个偏好" |

---

## 一、自动化触发点

### 1.1 对话开始时（自动）

```
触发：每次新对话开始
动作：
  1. 读取会话记忆.md
  2. 读取用户偏好.md
  3. 恢复上下文
  4. 识别用户情绪（从第一句话）
提示：仅在有中断任务时显示
```

### 1.2 对话进行中（自动）

```
触发：用户每次回复
动作：
  1. 实时识别情绪变化
  2. 捕获明确表达的偏好
  3. 记录关键决策
提示：不提示，静默记录
```

### 1.3 内容生成后（自动）

```
触发：AI 生成内容后
动作：
  1. 等待用户反馈
  2. 如果用户修改 → 对比差异
  3. 如果用户说"不对" → 记录问题
提示：不提示，静默记录
```

### 1.4 对话结束时（自动）

```
触发：对话即将结束（用户长时间无回复）
动作：
  1. 保存当前任务状态到会话记忆
  2. 更新用户偏好（如有变化）
  3. 处理累积的反馈记录
提示：不提示，静默保存
```

## 二、自动识别机制

### 2.1 情绪识别（实时）

**触发**：用户每次回复

**识别规则**：

| 情绪状态 | 识别特征 | 自动动作 |
|---------|---------|---------|
| 焦虑/急躁 | "快点"、"直接说"、连续追问 | 切换到极简回复模式 |
| 探索/好奇 | "为什么"、"还有什么"、主动提问 | 可以展开讲解 |
| 疲惫/厌烦 | 回复简短、"算了"、"不用了" | 简化流程，减少询问 |
| 兴奋/投入 | 主动分享、连续对话、"太好了" | 可以深入讨论 |

**记录位置**：`用户偏好.md` > 当前情绪状态（动态更新）

**提示**：不提示，静默调整回复策略

### 2.2 偏好捕获（实时）

**触发**：用户表达偏好时

**识别规则**：

| 表达方式 | 示例 | 自动动作 |
|---------|------|---------|
| 明确否定 | "我不喜欢xxx" | 立即记录到用户偏好 |
| 明确肯定 | "就是这样"、"对，这个好" | 记录当前方式为偏好 |
| 要求改变 | "以后都这样"、"别再xxx" | 立即更新偏好 |
| 重复纠正 | 连续 2 次修改同类内容 | 记录到反馈记录 |

**记录位置**：`用户偏好.md` 或 `反馈记录.md`

**提示**：仅在明确表达时轻度确认："好的，已记住"

### 2.3 修改识别（自动）

**触发**：用户修改 AI 生成的内容

**识别方式**：

1. **直接修改文件**：对比 git diff
2. **重新生成**：对比两次生成的差异
3. **明确指出**：用户说"这里不对"

**识别内容**：

| 修改类型 | 识别方法 | 自动动作 |
|---------|---------|---------|
| 词汇替换 | 对比词汇差异 | 记录到反馈记录 |
| 句式调整 | 对比句子结构 | 记录到反馈记录 |
| 语气修改 | 对比标点符号 | 记录到反馈记录 |
| 结构调整 | 对比段落顺序 | 记录到反馈记录 |
| 内容增删 | 对比内容长度 | 记录到反馈记录 |

**累积规则**：
- 单次修改 → 记录到反馈记录
- 累积 3 次同类修改 → 自动更新到风格档案
- 用户明确说"记住" → 立即更新

**提示**：
- 第 1-2 次：不提示
- 第 3 次（达到阈值）：轻度提示"已学习到你的偏好：xxx"

## 三、自动保存机制

### 3.1 会话记忆（对话结束时）

**触发**：对话结束时自动保存

**保存内容**：
- 当前进行中的任务
- 本次对话的关键决策
- 临时偏好（如有）
- 未完成的讨论话题

**保存时机**：
- 用户说"先这样"、"等会再说"
- 用户长时间无回复（5 分钟）
- 对话自然结束

**提示**：不提示，静默保存

### 3.2 用户偏好（实时更新）

**触发**：识别到偏好变化时

**更新内容**：
- 语言风格偏好
- 当前情绪状态
- 工作习惯偏好
- 内容创作偏好

**更新时机**：
- 用户明确表达偏好 → 立即更新
- 识别到行为模式 → 累积后更新
- 情绪状态变化 → 实时更新

**提示**：
- 明确表达 → 轻度确认"好的，已记住"
- 行为模式 → 不提示
- 情绪变化 → 不提示

### 3.3 反馈记录（累积更新）

**触发**：识别到修改时

**记录内容**：
- 修改类型
- 修改前后对比
- 累积次数

**更新时机**：
- 每次修改 → 立即记录
- 累积 3 次 → 自动更新到风格档案

**提示**：
- 第 1-2 次 → 不提示
- 第 3 次 → 轻度提示"已学习到你的偏好"

## 四、自动化工作流

### 4.1 对话开始

```
用户：[开始对话]
    │
    ▼
AI：自动读取会话记忆和用户偏好
    │
    ▼
AI：识别用户情绪（从第一句话）
    │
    ▼
AI：调整回复策略
    │
    ▼
AI：显示仪表盘（如有中断任务）
```

### 4.2 对话进行中

```
用户：[回复]
    │
    ▼
AI：实时识别情绪变化
    │
    ├─ 情绪变化 → 调整回复策略
    │
    ├─ 明确表达偏好 → 立即记录
    │
    └─ 做出关键决策 → 记录到会话记忆
    │
    ▼
AI：生成回复
    │
    ▼
用户：[修改内容]
    │
    ▼
AI：对比差异，记录到反馈记录
    │
    ├─ 累积 < 3 次 → 静默记录
    │
    └─ 累积 = 3 次 → 更新风格档案 + 轻度提示
```

### 4.3 对话结束

```
用户：[长时间无回复]
    │
    ▼
AI：判断对话是否结束
    │
    ▼
AI：保存当前任务到会话记忆
    │
    ▼
AI：更新用户偏好（如有变化）
    │
    ▼
AI：处理累积的反馈记录
    │
    ▼
AI：静默保存，不提示
```

## 五、提示策略

### 5.1 静默学习（不提示）

**适用场景**：
- 情绪识别
- 行为模式记录
- 第 1-2 次修改
- 对话结束时保存

**原则**：完全无感，用户不知道 AI 在学习

### 5.2 轻度提示（简短确认）

**适用场景**：
- 用户明确表达偏好
- 累积 3 次修改（达到阈值）
- 识别到重要模式

**提示方式**：
- "好的，已记住"
- "已学习到你的偏好：xxx"
- 不超过 1 行

### 5.3 询问确认（可选）

**适用场景**：
- 偏好冲突（新旧偏好矛盾）
- 重要决策（如删除大量内容）

**提示方式**：
- "之前你说 xxx，现在说 xxx，以哪个为准？"
- 给出选项，让用户选择

## 六、实现要点

### 6.1 在 AGENTS.md 中集成

**开局协议**：
- 步骤0：自动读取会话记忆和用户偏好（已有）
- 步骤0.5：识别用户情绪（新增）

**对话进行中**：
- 每次回复前：检查情绪变化
- 每次生成后：等待反馈，自动识别修改

**对话结束时**：
- 自动保存会话记忆
- 自动更新用户偏好
- 自动处理反馈记录

### 6.2 在风格学习师中集成

**自动触发**：
- 用户修改内容 → 自动对比差异
- 用户说"不对" → 自动记录问题
- 累积 3 次 → 自动更新风格档案

**手动触发**（保留，但不强调）：
- "记录这次反馈" → 立即记录
- "学习我的修改" → 立即分析

### 6.3 在用户偏好中集成

**自动更新**：
- 情绪识别 → 实时更新当前情绪状态
- 偏好捕获 → 立即更新偏好档案
- 行为模式 → 累积后更新

**手动更新**（保留，但不强调）：
- "记住这个偏好" → 立即更新

## 七、用户体验

### 7.1 理想体验

```
用户：[正常使用工作流]
AI：[后台自动学习，不打扰]

--- 几次对话后 ---

用户：[发现 AI 越来越懂自己]
用户：[不需要重复纠正]
用户：[回复风格越来越符合预期]
```

### 7.2 避免的体验

```
❌ 用户：写一篇文章
   AI：请先说"记录这次反馈"

❌ 用户：[修改内容]
   AI：检测到修改，是否记录？

❌ 用户：[每次都要手动触发]
```

### 7.3 期望的体验

```
✅ 用户：写一篇文章
   AI：[生成内容]

✅ 用户：[修改内容]
   AI：[静默记录，不打扰]

✅ 用户：[第 3 次同类修改]
   AI：已学习到你的偏好：xxx
```

## 八、开关控制（可选）

如果用户不想要自动学习，可以关闭：

```
用户：暂停自动学习
AI：[停止自动记录，只保留手动触发]

用户：恢复自动学习
AI：[恢复自动记录]
```

**默认**：自动学习开启

## 九、总结

### 核心改变

| 之前 | 现在 |
|------|------|
| 需要说"记录这次反馈" | 自动识别修改，静默记录 |
| 需要说"记住这个偏好" | 自动捕获偏好，立即更新 |
| 需要说"上次说到哪了" | 自动恢复上下文，无需询问 |
| 手动触发为主 | 自动化为主，手动触发为辅 |

### 用户感知

- **90% 的时间**：完全无感，AI 在后台学习
- **10% 的时间**：轻度提示，确认学习结果
- **0% 的时间**：不需要主动触发

### 实现优先级

1. **高优先级**：情绪识别、偏好捕获、修改识别
2. **中优先级**：自动保存、累积更新
3. **低优先级**：手动触发（保留但不强调）
