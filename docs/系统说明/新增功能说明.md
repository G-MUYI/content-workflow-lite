# 新增功能说明

> 2026-03-05 更新：会话持久化 + 反馈学习机制

---

## 新增功能概览

### 1. 会话持久化

**解决的问题**：对话中断后，AI 无法记住上次的进度和上下文。

**新增文件**：
- `skills/_通用/会话记忆.md` - 记录跨会话的上下文信息

**功能**：
- 自动记录当前进行中的任务
- 保存最近 3 次对话的关键决策
- 记录临时偏好（如"这次写得轻松一点"）
- 追踪未完成的讨论话题

**使用方式**：
- 自动触发：每次对话开始时自动读取
- 手动触发：说"上次说到哪了"或"继续上次的"

---

### 2. 用户偏好追踪

**解决的问题**：AI 不了解你的语言风格、工作习惯、情绪模式。

**新增文件**：
- `skills/_通用/用户偏好.md` - 记录长期偏好

**功能**：
- 语言风格偏好（正式度、幽默感、回复长度）
- 情绪模式识别（焦虑/探索/疲惫/兴奋）
- 工作习惯偏好（节奏、自主性、完成度）
- 内容创作偏好（选题、写作节奏、标题风格）
- 协作偏好（沟通方式、自动化程度）

**使用方式**：
- 自动学习：AI 从你的行为中识别模式
- 手动更新：说"记住这个偏好"

---

### 3. 反馈学习机制

**解决的问题**：AI 无法从你的修改中学习，每次都要重复纠正。

**新增文件**：
- `skills/_通用/风格档案/反馈记录.md` - 临时记录修改模式

**功能**：
- 自动识别你的修改（词汇替换、句式调整、语气修改）
- 累积同类修改，达到阈值后自动更新风格档案
- 分析修改原因，提取偏好模式

**使用方式**：
- 自动学习：AI 自动对比你的修改
- 手动触发：说"记录这次反馈"或"学习我的修改"

## 工作流变化

### 开局协议流程

**之前**：
```
步骤1：扫描选题库
步骤2：输出仪表盘
步骤3：给出下一步建议
```

**现在**：
```
步骤0：读取会话记忆（新增）
  ├─ 读取会话记忆.md
  ├─ 读取用户偏好.md
  └─ 显示中断的任务

步骤1：扫描选题库
步骤2：输出仪表盘
步骤3：给出下一步建议
```

### 反馈学习流程

```
你修改 AI 输出
    │
    ▼
AI 自动识别修改类型
    │
    ▼
记录到反馈记录.md
    │
    ▼
累积到阈值（3 次）
    │
    ▼
自动更新风格档案
```

## 使用示例

### 示例 1：任务中断恢复

```
第一次对话：
你：我要写一篇关于 AI 工具的文章
AI：[生成选题] 已入库，要现在策划吗？
你：好，策划
AI：[生成大纲] 大纲已定，要现在写吗？
你：等会再写，我先去吃饭
AI：[自动记录到会话记忆]

第二次对话：
AI：[自动读取会话记忆]
    🔄 上次中断的任务
    · 写 AI 工具文章 — 已完成策划 — 下一步: 说"写"开始写作

你：继续
AI：好的，现在开始写作...
```

### 示例 2：偏好学习

```
第 1 次：
AI：综上所述，这个方案可行。
你：[修改为] 好了，这个方案可行。
AI：[记录到反馈记录，累积 1 次]

第 2 次：
AI：综上所述，我们可以开始了。
你：[修改为] 好了，可以开始了。
AI：[记录到反馈记录，累积 2 次]

第 3 次：
AI：综上所述，任务完成。
你：[修改为] 好了，任务完成。
AI：[达到阈值，自动更新风格档案]
    📝 已学习到你的偏好：
    · 禁用词：综上所述
    · 替代词：好了
    以后会自动使用"好了"代替"综上所述"。

第 4 次：
AI：好了，这个方案可行。
你：✅ 对了，就是这样
```

### 示例 3：情绪识别

```
你：快点，直接说结论
AI：[识别情绪 = 焦虑/急躁]
    [调整回复策略 = 极简回复]

    结论：方案可行，立即执行。

你：[后续对话恢复正常]
AI：[识别情绪恢复]
    [恢复正常回复长度]
```


正常使用工作流，AI 会自动：
- 记录会话上下文
- 学习你的偏好

## 注意事项

### 1. 隐私

所有记忆和偏好都存储在本地文件中，不会上传到云端。

### 2. 清理

- 会话记忆：任务完成后自动清理
- 反馈记录：更新到风格档案后可手动清理
- 用户偏好：长期保留，可手动修改

### 3. 冲突处理

当新偏好与旧偏好冲突时，AI 会询问你以哪个为准。

### 4. 学习阈值

- 默认阈值：3 次同类修改
- 明确指令：说"记住这个"立即生效
- 可调整：修改反馈记录.md 中的阈值设置

## 常见问题

**Q：会话记忆会一直保留吗？**
A：不会。任务完成后自动清理，只保留最近 3 次对话的关键决策。

**Q：如何关闭自动学习？**
A：说"暂停自动学习"，需要时说"恢复自动学习"。

**Q：如何查看当前偏好？**
A：说"查看我的偏好"或"风格档案状态"。

**Q：可以手动编辑这些文件吗？**
A：可以。所有文件都是 Markdown 格式，可以直接编辑。
